# 개발 결과 보고 규칙

작업 번호별로 HWR-001.md와 같은 파일을 작성한다. 보고가 수정되면 수정 시각을 한국시간과 UTC로 남긴다. 새 작업의 보고로 기존 작업 보고를 덮어쓰지 않는다.

## 보고에 포함할 내용

- 작업 번호와 읽은 지시서 경로
- 시작 및 완료 시각
- 상태: 완료, 일부 완료, 차단 중 하나
- 작업을 시작한 브랜치와 기준 커밋
- 엔진 버전과 실행 환경
- 구현한 동작과 주요 변경 파일
- 프로젝트 실행 방법
- 실제 수행한 검증과 결과
- 미수행 검증과 그 이유
- 남은 오류 또는 기획과의 차이
- 사용자가 직접 플레이하며 확인할 항목
- 코드 변경 커밋과 원격 반영 여부

완료 보고 자체를 포함하는 커밋의 해시를 미리 추측해 적지 않는다. 확인된 코드 커밋이나 작업 기준 커밋을 기록한다. 체감상 재미와 기술적 동작 확인을 구분한다.
