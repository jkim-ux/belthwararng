## 게임 표시

`game/scripts/village/spirit_actor_3d.gd`에도 낮고 넓은 몸, 깊게 겹친 머리, 작은 눈·부리, 옅은 볼, 납작한 갈색·흰색 날개와 꼬리, 작은 발을 반영했다. 게임의 기존 가벼운 메시를 수정한 것이며 ZIP의 GLB를 게임 표시와 연결하는 작업은 포함하지 않는다.

## 직접 수행한 검증

- Godot 4.7.2 공식 Linux headless.
- Khronos Validator: GLB 14개 오류 0·경고 0.
- Godot 가져오기, 6개 동작·물레 회전·미리보기 장면 검사 통과.
- 기존 `test_v18_spirit_states_wander_and_effects`: 16개 검사 통과, 실패 0.
- GLB를 직접 읽은 ModernGL/EGL 정면·측면·후면·농장·6개 동작 GIF와 work/rest 자세를 확인했다.
- 수정 전후를 동일 카메라·조명·배율에서 함께 렌더링했다. 2D 컨셉 이미지를 실제 실행 결과로 제시하지 않았다.
- ZIP CRC·모델 SHA-256 검사. 농장 GLB 13개는 v1.2와 해시가 동일하고 정령만 변경됐다.
- `git diff --check` 확인.
