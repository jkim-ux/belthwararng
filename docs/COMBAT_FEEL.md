## 2. 유지할 기준
초기 비교에서는 M1의 이동 300/200px/s, 가속/감속 50/40ms, 점프, 회피, 공격 준비/타격/회복 시간, 120ms 입력 보관, 연결창, 피해 계수, 깊이·높이 범위를 유지한다.
바닥 위치와 점프 높이는 계속 분리한다. 상하 이동을 점프/연출로 바꾸지 않는다.
지상 평타만 새 모멘텀을 적용한다. 공중 평타와 A 돌진, S 올려베기는 기존 이동 규칙을 유지해 이중 전진을 막는다.
타격 정지는 기존 구현의 일반 2틱/강공격 4틱에서 시작한다. 여러 적에게 맞혔다고 정지 시간을 더하지 않는다. 입력은 정지 중에도 수집한다.
기존 키: 방향키 이동, X 평타, C 점프, Space 회피, A/S 스킬. 새 기능 때문에 기본 조작 키를 바꾸지 않는다.

## 3. 평타 전진과 적 밀림을 함께 맞춘다
수치는 최종 밸런스가 아니라 A/B 비교 초기값이다. 초기안 변경은 이유와 실제 값을 보고한다.

| 항목 | 1타 | 2타 | 3타 |
| --- | --- | --- | --- |
| 성격 | 짧은 진입 | 이어 베기 | 체중을 싣는 마무리 |
| 준비/타격/회복 ms | 80/50/170 유지 | 70/50/180 유지 | 100/70/230 유지 |
| 공격자 추가 전진 px | 12 | 18 | 30 |
| 일반 적 밀림 px | 12 | 18 | 65 |
| 적 밀림 기간 ms | 100 | 120 | 180 |
| 타격 정지 | 2틱 | 2틱 | 4틱 |
| 피해 계수 | 100% 유지 | 100% 유지 | 140% 유지 |
| 시각 방향 | 가로베기 | 반대 방향 가로베기 | 크게 내려오는 사선베기 |

1/2타는 적과 주인공의 이동 거리를 비슷하게 해 적이 사거리 밖으로 밀려나는 현상을 줄이고, 3타에 거리 벌리기를 맡긴다. 자동 추적이나 적에게 순간 이동하는 보정은 넣지 않는다.
수련장 허수아비는 원래처럼 밀리지 않는 고정 표적을 유지한다. 밀리는 표적과 일반 적을 따로 확인한다. 연속 평타가 일반 적을 한 세트에 죽여도 검증할 수 있도록 체력이 큰 검증용 표적을 사용할 수 있다.

### 전진 계산
N = 고정 틱으로 환산한 타격 구간 길이. 데이터에서 N은 최소 1이다.
누적 전진 곡선은 C(u)=1-(1-u)^2, u는 0~1. 타격 구간 k번째 진행 틱의 이동량은 D×(C((k+1)/N)-C(k/N))이다. 방향은 공격 시작 때 고정된 좌우 방향이다.
이 방식으로 이른 틱에 크게 나가고 끝에서 감속하며, 모든 틱의 전진 합은 장애물이 없을 때 D가 된다. 애니메이션 렌더 프레임에서 별도 이동하지 않는다.
준비 구간에서는 기존 잔여 지상 속도를 감속한다. 타격 구간에서는 평타 전진이 x 이동을 맡고 잔여 x 속도를 중복 더하지 않는다. y는 기존대로 감속하며 자동으로 적의 깊이를 추적하지 않는다.
타격 정지에서는 전진/피격 밀림/몸 동작의 진행 시간을 모두 멈춘다. 정지 해제 후 남은 틱부터 재개하며 빠진 이동을 한 번에 보충하지 않는다.
회피 연결, 피격, 사망, 장면 전환으로 공격이 끝나면 미실행 전진량을 폐기한다. 다음 행동에 속도나 이동량이 새어 나가지 않아야 한다.
경계에 막히면 이동을 그 자리에서 잘라내고 남은 거리를 나중에 누적 적용하지 않는다. 단순 도형 단계에서는 기존 개체 통과 정책을 유지하며 전신 물리 충돌 시스템을 새로 추가하지 않는다.

### 피격 밀림
일반 적은 타격 정지 뒤 정해진 기간 동안 같은 누적 곡선으로 총 거리를 소모한다. 경직 시간과 밀림 시간을 분리하여 이동을 마친 뒤에도 남은 경직은 유지할 수 있다.
새 타격을 받으면 해당 타격의 밀림으로 교체한다. 여러 타격의 속도를 무한 합산하지 않는다. 여러 공격이 같은 틱에 들어오면 피해는 각 인스턴스 규칙대로, 피격 이동은 마지막 적용 순서 등 하나의 결정된 규칙을 사용하고 테스트한다.
이번 밀림 변경은 지상의 일반 적 평타 피격부터 적용한다. 기존 공중 적의 중력·재띄우기 금지, 다운·기상 보호, 플레이어 피격 처리는 유지한다. 보스와 동료의 예외는 캠페인 상세 규칙을 따른다.

## 4. 몸체·검·적중 연출
몸체의 기울기와 짧은 시각 오프셋은 그림에만 적용하고 발 위치, 그림자, y 정렬, hurtbox, 점프 높이를 바꾸지 않는다.
준비: 짧게 뒤로 당기고 검을 모은다. 80ms를 더 늘려 예비동작을 보이게 하지 말고 기존 틱 안에서 보이게 한다.
타격: 몸과 검이 같은 공격 시간으로 전방에 실린다. 1/2타는 방향이 반대인 궤적, 3타는 큰 사선으로 구분한다. 잔상은 짧게 소멸한다.
회복: 원래 자세로 돌아오되 이미 정해진 입력 연결/회피 시점을 애니메이션 완료 때문에 늦추지 않는다.
헛치기: 몸과 검은 나가지만 적중 섬광·피격 움찔·적중음·타격 정지는 없다.
적중: 실제 hit_confirm 이벤트로 섬광과 피격 반응을 발생시킨다. 한 번의 타격으로 맞힌 대상마다 작은 섬광은 가능하지만 화면 전체 효과는 합산하지 않는다.
검 궤적은 화면상 실제 공격 도달 범위와 크게 어긋나지 않게 하고, 과장된 사거리 증가 대신 기존 판정의 폭 안에서 먼저 조절한다. 높이 판정은 기존 값을 유지한다.
사운드는 프로젝트에 사용 가능한 재료가 있을 때 간단한 휘두름/적중음을 더한다. 소리가 없어도 움직임과 판정 검증은 가능해야 한다. 카메라 흔들기는 기본 0이며 필수 구현이 아니다.

## 5. 비교 장치
수련장에서만 '기존 M1 / 새 모멘텀' 프로필을 선택한다. 프로필 전환은 행동이 끝난 상태 또는 재설정 후 적용한다.
기존 프로필은 전진 0/0/0, 밀림 30/30/70의 기존 일정 속도, 기존 검 표시를 사용한다. 새 프로필은 이 문서의 전진·밀림·시각 동작을 사용한다. 체력, 피해, 타이밍, 대상 시작 위치는 비교할 때 동일하다.
설정이 공유 Resource를 수정하여 다른 개체/저장 게임에 남지 않게 한다. 캠페인은 새 프로필 고정이며 비교 실험이 영구 진행 상태를 변경하지 않는다.
F1은 발 위치, 전진량, 공격 구간, 판정 범위, 밀림 잔여량 확인에 쓴다. F5/F6 재생성·초기화는 수련장에서만 허용한다.

## 6. 필요한 검증
- 좌우 방향 각각에서 정지 후 단독 평타 전진 합이 12/18/30px. 타격 정지가 있어도 총 추가 거리는 같고 그동안 이동은 멈춘다.
- 경계에서 밀리지 못한 거리나 취소한 공격의 거리가 다음 평타/회피에 더해지지 않는다.
- 같은 깊이에서 앞쪽 70~90px에 둔 살아 있는 피격 표적에 평타 3타가 지정 연결 입력으로 모두 닿는다. 과한 밀림 때문에 2/3타가 끊기지 않는다.
- 위 테스트를 왼쪽 바라보기, 적을 벽에 붙인 경우, 헛치기 후 연결에서도 확인한다. 판정을 무한 확장해 통과시키지 않는다.
- 깊이 불일치, 높이 불일치, 한 타 한 대상 1회, 다수 적 히트스톱 비합산, 입력 만료, 점프/회피, A/S 스킬의 기존 검증을 유지한다.
- 렌더 제한 30/60/120에서 고정 시뮬레이션의 전진 합과 타이밍을 비교할 수 있으면 실행하고 환경을 적는다. 미수행은 그대로 기록한다.

사용자 플레이 확인은 별도다: '3타가 가장 무겁게 느껴지는가', '1/2타가 맞은 적을 따라가며 연결되는가', '헛쳤을 때와 맞혔을 때 구분되는가', '기존 이동/회피 반응이 유지되는가'. 이 평가는 기획 담당이나 테스트 코드가 대신 통과시킬 수 없다.
