# HWR-005 — 직접 가꾸는 마을: 개간·건설·관개·주민 작업
작성: 2026-09-12 20:53:40 KST / 2026-09-12T11:53:40Z
기준: [GAME_DESIGN](GAME_DESIGN.md), [기존 캠페인·저장](CAMPAIGN_SYSTEMS.md).
범위: 기존 챕터1 위에 실제 마을 공간과 건설·생산을 구현한다. 수치는 첫 플레이 검증용 설계값이다.

## 1. 사용자 요구와 이번 목표
사용자는 현재 마을 기능이 제한적이고 군자금만 지불하는 방식으로는 부족하다고 했다. 농장에 필요한 개간과 물 공급, 댐 건설 등 기반 시설을 세분화하고, 캐릭터로 마을을 돌아다니며 건물을 직접 놓고 가꾸길 원한다.
참고 방향은 자원을 모아 건물을 세우고 공동체를 키우는 [Cult of the Lamb의 공식 소개](https://store.steampowered.com/app/1313140/Cult_of_the_Lamb/)다. 아래 관개·자원·배치·생산 수치는 이 프로젝트를 위한 별도 설계다.
이번 플레이 목표: 해방된 농촌 입장→나무/돌/덤불 정리→농장·우물·수로 직접 배치→건설 작업→주민에게 농사 배정→자라는 작물 확인→식량 수확→벌목/채석 작업에 식량 공급→강가 보와 추가 농장으로 확장.
전투는 기존 벨트스크롤을 유지한다. 마을은 바닥 x/y로 자유 이동하는 독립 장면이며, 점프 높이·피해 판정이 마을 작업에 필요하지 않다. 주민은 생산/건설을 담당하고 해금된 전투 동료는 기존 출정 시스템을 따른다.

## 2. 공간과 직접 설치하는 조작
농촌(ch1_farm)과 창고(ch1_store)에 같은 건설 시스템을 사용하는 별도 배치 상태를 둔다. 농촌에는 비옥한 들판·강가, 창고에는 창고 마당·작은 텃밭·강가로 구별한 고정 템플릿을 제공한다. 초소(ch1_pass)는 기존 군사 거점이며 건설 마을로 바꾸지 않는다.
각 템플릿은32×24칸, 한 칸48px 초기값. 나무·바위·비옥한 땅·강·절벽·출입구·중앙 통행로·고정 복구 현장을 데이터로 정의한다. 해방 전에는 들어갈 수 없고 첫 승리 후 지도에서 '마을 들어가기'를 제공한다. 반환 경로는 마을 출입구→기존 캠페인 지도→출정이다.

| 조작 | 동작 |
| --- | --- |
| 방향키 또는 WASD | 마을 캐릭터 이동 |
| E | 가까운 건물/주민 상호작용, 자원/공사 현장에서는 길게 눌러 작업 |
| B | 하단 건설 목록 열기/닫기 |
| 마우스 이동·좌클릭 | 반투명 건물 미리보기 이동·유효 위치 확정 |
| R | 회전 가능한 건물을90도 회전 |
| 우클릭 또는 Esc | 현재 배치 취소, 목록으로 복귀 |
| 건물 선택→이동 | 기존 위치를 보존한 채 새 위치 미리보기 |
| 관개 보기 | 수원·연결된 수로·물 공급 농장을 겹쳐 표시 |

전투 스킬 키 입력과 마을 입력 컨텍스트를 분리한다. UI 클릭이 뒤쪽 설치/작업으로 동시에 전달되면 안 된다. 캐릭터를 움직이면서 배치 위치를 살펴볼 수 있게 카메라가 따라간다.
건물은 격자에 스냅한다. 점유 크기·문/작업 위치·회전 방향·비용을 미리 보여준다. 불가 이유는 '강 위', '나무 제거 필요', '통로 막힘', '목재8 부족'처럼 짧게 표시한다. 색과 ✓/×를 함께 사용한다.
마을 공간이 화면의75% 이상을 차지하고 상단에는 군자금/목재/석재/식량/배정 가능한 주민, 하단에는 아이콘 건설 목록을 둔다. 건물 설정·주민 배정은 선택 대상의 작은 패널이다. 기존 관리 화면의 긴 목록이 주 화면이 되지 않게 한다.

## 3. 자원과 시작 조건
| 항목 | 얻는 방법 | 사용처 |
| --- | --- | --- |
| 군자금 | 기존 거점 최초100/반복20, 선택 상자30 | 복구 공사·특수 시설·보 건설 |
| 목재 | 나무 개간, 벌목소 | 일반 건설·수로·주택 |
| 석재 | 바위 개간, 채석장 | 우물·보·튼튼한 시설 |
| 식량 | 농장 수확 | 벌목/채석 작업의 식사 |
| 주민 | 각 마을 초기3명, 주택 완공 시 귀환 | 한 명당 하나의 건설/생산 작업 |

군자금·목재·석재·식량은 해방 마을이 공유하는 저장고다. 주민·건물·농장·수로는 마을별이다. 별도 운송 무역은 후속 확장이다.
첫 농촌 마을 초기화에 한 번 목재60/석재40/식량20을 복구 물자로 지급한다. 기존 군자금은 그대로다. 창고 첫 초기화에는 주민3명과 공간만 제공하며 공유 자원을 다시 지급하지 않는다. 재입장/로드/재승리/저장 재시도로 물자가 복제되면 안 된다.
출정은 계속 무료이며 식량 부족이 전투 진입을 막지 않는다. 주민 굶주림 사망·이탈·질병은 이번 범위에 없다. 식량0이어도 농사는 정상 생산하고 벌목/채석만 절반 생산하므로 마을이 복구 불가능해지지 않는다.
자원은 음수가 될 수 없다. 공간/자원/조건을 모두 검증한 뒤 설치 확정에 한 번 차감한다. 가방 크기·새 화폐·씨앗/도구 내구도는 이번 생산 순환에 필요하지 않다.

## 4. 개간과 건설
땅은 처음부터 전부 빈 격자가 아니다. 덤불/나무/돌을 치워 건물 크기만큼의 공간을 만든다.
초기 장애물: 덤불1초(자원0), 작은 나무2초(목재4), 바위3초(석재3). 인접해 E를 누르는 동안만 진행하며 누름을 멈춰도 진행량은 유지한다. 완료 시 장애물 제거+보상은 같은 작업 ID로 한 번 처리한다.
기본 빈터에서 복구 현장과 벌목소/채석장 자리까지 항상 걸어갈 수 있고, 개간에 자금·도구 선행 조건은 없다. 나무/바위는 유한하고 같은 ID가 재입장 때 되살아나지 않는다. 장기 목재/석재는 생산 시설에서 얻는다.

건설은 미리보기→설치 확정/비용 차감→자재 더미/기초→공사→완공 순서다. 메뉴에서 확인한 순간 완성 건물이 튀어나오지 않는다.
공사량은 작업량 단위로 정의한다. 플레이어 E 작업은 초당5, 배정 주민은 초당1을 진행한다. 한 현장에 주민 최대1명, 플레이어와 주민은 합산 가능하다. 건설 노동은 식량을 소모하지 않는다.
공사 중에도 점유 칸을 예약하며 완공 전 효과·주민 증가·농사 생산은0이다. 공사 현장 앞에 작업 위치가 있어야 한다. 작업 중 목표가 취소/이동/제거되면 주민은 작업을 해제하고 기존 위치에서 새 경로를 구한다.
공사 취소는 투입 자원100%를 반환하고 공사량은 폐기한다. 완공 건물 이동은 무료이며 상태/주민/작물 진행과 고유 ID를 유지한다. 이동 확정 전 원래 점유를 없애지 않으며 이동 취소로 복제하지 않는다.
완공 농장/우물/보/수로/생산 시설은 철거 시 원재료100%를 반환하되 진행 중 생산물은 지급하지 않는다. 철거 후 같은 건물을 다시 지어도 초기화 보상은 없다. 주택·훈련장·보급창·필수 복구 현장은 이동만 허용하고 철거는 제공하지 않는다. 경로 복구 현장·보는 정해진 지형 위치가 있어 이동 불가다.

## 5. 건물 목록과 초기 비용
아래 크기는 점유 칸, 비용 표기는 군자금/목재/석재다. 별도 기입이 없으면 첫 해방부터 사용 가능하다.

| 건물 | 크기 | 비용 | 공사량 | 기능·제한 |
| --- | --- | --- | --- | --- |
| 농장 | 3×3 | 0/10/2 | 30 | 비옥한 개간지, 물과 농부1명, 30초에 식량6 |
| 우물 | 2×2 | 0/8/6 | 30 | 일반 지면, 연결 농장2개에 물 공급 |
| 수로 | 1×1 | 0/1/0 | 5 | 개간 지면에 직접 배치, 수원과 농장 연결 |
| 작은 보(관개용 댐) | 3×2 | 30/20/20 | 60 | 마을당 강가 지정 자리1개, 연결 농장4개에 물 공급 |
| 벌목소 | 2×2 | 0/12/2 | 30 | 고정 숲 작업 구역에 접한 자리, 주민1명, 20초에 목재6 |
| 채석장 | 2×2 | 0/8/8 | 30 | 고정 암반 작업 구역에 접한 자리, 주민1명, 20초에 석재4 |

훈련장/보급창은 완공 시 기존 구매 플래그를 설정하며 여러 건물/로드로 효과를 중첩하지 않는다. 주민 배정이나 일시 생산 정지로 기존 영구 효과를 껐다 켜지 않는다.
숲·암반 작업 구역은 마을 경계의 고정 생산 지형이다. 개간 가능한 나무/돌이 소진돼도 벌목소/채석장이 작동한다. 각 마을에 최소 한 자리씩 확보한다.
우물은 작은 농장에 먼저 투자하는 선택, 보는 군자금·석재를 더 들여 농장을 넓히는 선택이다. 물은 소비 화폐가 아니라 연결망의 공급 용량이다.
첫 반복 사냥 없이 핵심 복구를 할 수 있는 예: 초기60/40과 농촌 승리 군자금100에서 농장+우물+수로8칸+경로 복구+훈련장 비용은 군자금100/목재48/석재19다. 남는 목재12/석재21, 식량20으로 시작하고 추가 시설은 개간/생산으로 마련한다. 보는 필수 진행 비용에 넣지 않는다.

## 6. 농사와 물길
농장 설치 조건은3×3 전체가 비옥하고 개간 완료이며 점유 충돌이 없는 것이다. 물 없이도 설치할 수 있지만 미리보기부터 '물 공급 필요'를 표시하고 물이 없으면 성장하지 않는다.
농장은 빈 밭→파종/작은 싹→성장→수확 직전의 모습으로 바뀐다. 유효 작업30초를 채우면 식량6을 한 번 저장고에 보내고 새 작물 주기를 시작한다. 0~10초/10~20초/20~30초의 세 성장 단계를 구분한다.
완공·물 공급·농부 배정·작업 위치 도착이 모두 충족되어야 성장한다. 조건이 끊기면 진행량을 보존하고 멈춘다. 다시 연결하면 남은 시간만 진행한다. 농장에 주민이 없을 때 플레이어가 인접해 E로 대신 일할 수도 있으며 성장 속도는 초당1 작업초로 동일하다. 주민과 플레이어가 동시에 농사해도 두 배 수확하지 않는다.

수원은 우물과 보의 물 출구, 수로는 상하좌우 연결이다. 대각선은 연결하지 않는다. 농장 가장자리의 한 칸이 젖은 수로나 수원 출구와 상하좌우로 접하면 후보가 된다. 동일 농장의 여러 면 접촉은1개로 센다. 서로 떨어진 물망2개에 닿은 농장도 용량은 한 번만 소비한다. 농장 생성 ID 순서로, 사용 가능한 물망 중 수원 ID가 가장 작은 망에 배정해 중복 공급/중복 성장하지 않는다.
완공된 연결망만 계산한다. 같은 연결망에 우물/보가 여러 개면 공급 용량은 합산한다. 농장당 용량1을 사용하고 부족하면 건물 생성 ID 순서로 먼저 공급한다. 공급/필요 수와 대기 농장에 '용수 부족'을 보여준다. 이동/철거로 ID를 재발급하지 않는다.
수로를 끊으면 해당 연결망을 다시 계산해 멀리 있는 농장의 성장도 멈춘다. 고리 연결에서도 무한 탐색하지 않는다. 분기 수로로 여러 농장에 물을 공급할 수 있다. 파란 수로/수원 연결선과 농장의 물방울 표시를 함께 쓴다.
보는 지정한 강가 부지에서 물을 막고 한쪽 육지 출구로 공급한다. 강 흐름·상류 저수/하류 농사 모습은 간단한 그림으로 표현하고 범람·실제 유체 시뮬레이션은 후속 작업이다.
농장·얕은 수로·길은 걸어갈 수 있다. 길과 수로는 같은 칸에 겹쳐 놓지 않는다. 일반 건물 본체는 통행을 막고 문/작업 칸은 비워 둔다.

## 7. 주민과 생산의 시간
주민은 이름/고유 ID/현재 작업을 가진다. 초기3명은 귀환 주민이며 아야 등 전투 동료와 별개다. 건물 선택→주민 배정에서 빈 주민을 선택하고 이미 일하는 주민을 옮기면 기존 배정은 해제된다. 한 주민이 여러 마을/작업에 동시에 기록되면 안 된다.
이번 자동 일감은 건설·농사·벌목·채석이다. 공사는 현장1개를 지정하며 완료 후 미배정으로 돌아온다. 자동으로 모든 공사를 가로채는 전역 우선순위 AI는 만들지 않는다.
주민은 실제로 경로를 따라 현장으로 걷고 도착한 뒤에 작업한다. 작업 모션·작물 변화·짧은 운반 동작을 보여준다. 생산 자원은 완료 이벤트에서 공유 저장고에 한 번 반영하며 운반 그림 도착 때 다시 지급하지 않는다.
벌목/채석 한 생산 주기가 시작될 때 식량1이 있으면 한 번 소비하고 정상 생산한다. 식량이 없으면 해당 주기 생산량은 목재3/석재2다. 주기 도중 식량이 생겨도 다시 소비하거나 산출량을 바꾸지 않는다. 주민 배정을 바꿔도 선지급 식량/주기 모드/진행량은 건물에 남고 중복 소비하지 않는다.
농사는 식량을 소비하지 않아 식량0에서 다시 생산 순환을 만들 수 있다. 주택 귀환은 완공 상태 전환당1회이며 이동/재로드로 주민이 늘지 않는다.

첫 구현의 경제 시간은 **현재 들어가 있는 마을에서만** 진행한다. 다른 마을·전투·지도·설정/일시정지·앱을 닫은 시간에는 생산과 공사를 멈추고 진행량을 저장한다. 건설 목록과 관개 보기에서는 계속 진행한다. 이 규칙을 마을 도움말에 한 줄로 알린다.
정착지 모형은10Hz 고정 작업 틱, 캐릭터 이동/연출은 기존 물리·렌더 틱을 사용한다. 생산과 공사는 공유한 틱 수/작업량으로 계산해 프레임률에 따라 생산량이 달라지지 않는다. 오프라인 시간이나 날짜 변경으로 생산하지 않는다.
이 버전은 공간 배치와 주민 작업을 검증하는 첫 단계다. 출정 중 배경 생산·주민 식사/휴식·세금·재난은 다음 피드백 뒤 확장한다.

## 8. 길 찾기와 배치 검증
확정 전에 지형, 점유 칸, 회전된 크기, 고정 부지, 해금/중복 제한, 자원, 출입구 및 작업 위치 접근을 모두 검증한다. UI 외에 상태 변경 API에서도 같은 규칙을 사용한다.
격자 탐색으로 마을 출입구/플레이어 위치/기존 건물의 작업 위치/새 작업 위치 사이 통행을 유지한다. 농장·길·수로는 통과 가능, 건물·미개간 장애물·강·절벽은 막힌 칸이다. 출입구와 고정 중앙 통행로는 건설 불가 예약 칸이다.
플레이어·주민이 서 있는 칸 위에 건물을 확정할 수 없다. 배치/이동 확정 후 주민의 기존 경로를 갱신한다. 막힌 주민을 건물 너머로 순간 이동시키거나 도착하지 않았는데 생산시키지 않는다.
농촌/창고 템플릿 각각에 농장3개 이상, 우물, 생산 시설2개, 주택2개, 특수 시설과 보 연결을 배치할 여유를 검수한다. 자유 배치를 허용하면서 진행 필수 공간은 항상 남긴다.
수로는 드래그해서 여러 칸을 미리 보고 한 번에 확정할 수 있다. 합계 비용/모든 칸 검증 후 전부 설치하거나 전부 취소한다. 일부 비용만 차감하거나 보이지 않는 연속 클릭으로 중복 설치하지 않는다.

## 9. 기존 진행·시설·저장과 연결
기준 구현 bf014527의 CampaignState는 schema1, currency/sites/facilities 중심이고 show_manage는 Control 버튼 화면이다. 그 위에 마을 장면과 영구 배치 모델을 추가한다. 게임 전체/전투 엔진을 재작성하지 않는다.
이제 새 경로 복구는40군자금+재료를 지불해 현장에서 공사해야 하며, 훈련장/보급창도 배치·완공해야 효과가 난다. 기존 repair/buy_facility 버튼이나 공개 호출로 건설을 건너뛰지 않게 한다. 같은 기능의 이전 규칙 중 이 부분은 본 문서가 우선이다.
새 게임 관리도는 기존처럼 미해방0→해방40→필수 복구 완공60. 농장/장식 개수로 숫자를 중복 누적하거나 기존60을 낮추지 않는다. 다음 거점 조건은 기존 관리도60·ID를 유지한다.

저장 schema2를 추가하고 실제 최신 구현이 이미 상위 형식이면 그 형식의 정상 이전 경로에 통합한다. 프로젝트 config/name·user:// 위치·기존 거점/시설/동료 ID를 유지한다.
추가 사실: wood/stone/food, 마을별 initialized/청소된 장애물 ID/개간 진행, 건물 ID·정의 ID·위치·회전·상태·공사 진행, 농사/생산 진행과 선지급 식사 모드, 주민 ID·배정, 일회성 복구 물자/주택 귀환 완료 기록, 다음 고유 ID.
물 연결·통행 격자·공격력·진입 가능 여부 등 파생값은 로드 후 재계산한다. 살아 있는 Node 참조·경로 탐색 배열·미리보기 상태를 저장하지 않는다.

schema1→2 이전:
1. 기존 자금·해방·관리도·시설·챕터·동료·last_committed_run_id를 그대로 가져온다.
2. 해방 마을에 고정 템플릿과 주민3명을 만든다. 미해방 마을은 첫 해방/진입 때 초기화한다.
3. repaired=true 마을은 비용을 다시 받지 않고 고정 복구 현장을 완공으로 넣는다. 이미 산 시설은 예약된 안전한 위치에 같은 시설 ID로 완공 배치한다. 효과+5%/+10은 기존 플래그에서 한 번만 계산한다.
4. 첫 농촌 초기화 물자60/40/20과 초기화 플래그를 동일 후보에 반영한다. 이전 재시도·반복 로드로 재지급하지 않는다.
5. 원본 정상 저장/백업을 보존한 뒤 새 형식을 검증·원자 저장한다. 실패하면 원본으로 계속 복구할 수 있어야 한다. 알 수 없는 상위 버전을 낮춰 읽지 않는다.

배치 확정/공사 취소/철거/이동/주민 배정/작업 완료/마을 출입 때 기존 후보 상태→검증→저장→메모리 반영 경로를 사용한다. 자원 차감·건물 생성·한 번 보상은 같은 후보에 포함한다. 생산/공사 중간 진행은10초마다, 완료 이벤트는 즉시 저장한다.
저장 실패 시 해당 후보를 보관하고 경제 틱과 추가 변경/출정을 정지해 '저장 재시도/이전 저장으로'를 제공한다. 재시도 때 생산물·주민·비용을 다시 계산하지 않는다. 생산 이벤트와 UI 입력이 같은 틱이면 순서대로 하나의 최신 상태에서 처리한다.
마을 진입/퇴장이나 배치만으로 전투 보상·상자 보너스를 재발급하지 않는다. 농사 주기를 완료하자마자 로드/이동/철거해도 같은 수확이 두 번 적용되면 안 된다.

## 10. 구현 순서와 완성 기준
1. 독립 Village 장면·카메라·이동·마우스 배치 미리보기·격자/점유/경로 검증을 구현한다.
2. 자원 상태·개간·비용 확정·공사·이동·취소와 기존 저장 이전을 연결한다.
3. 농장/우물/수로/보의 연결·용량·성장 표시를 구현한다.
4. 주민 걷기/배정/건설·생산, 벌목/채석/식사/주택 귀환을 연결한다.
5. 농촌·창고 템플릿, 복구 현장·기존 특수 시설을 연결하고 반복 플레이와 저장을 검수한다.

각 단계는 실행 가능한 커밋으로 남기되 이번 지시 완료는 위 전체 순환이 실제 작동할 때다. 스크린샷만 있는 마을이나 건설 버튼만 추가한 상태는 일부 완료다.
