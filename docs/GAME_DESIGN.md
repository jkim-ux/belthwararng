## 1. 이번 수정의 목적
사용자는 M1을 플레이한 뒤 이동·기본 전투·높이 판정을 수용했고, 공격에 몸이 실리는 느낌이 부족하다고 평가했다. 다음 요구는 사무라이 소재, 한 마을에서 시작하는 반격·점령전, 총 5챕터, 챕터 클리어마다 함께 싸우는 NPC 해금, 마을 시스템이다.
v0.2는 이 방향을 잡았으나 평타 전진과 적 밀림의 관계, NPC가 들어온 전투 판정, 마을 복구의 역할, 보상과 저장의 처리 순서가 부족했다. v0.3은 같은 HWR-002의 수정본이다. 이미 착수한 구현은 보존하고 변경된 요구만 적용한다.

| 확정된 사용자 요구 | 이번 구현을 위해 정한 초기안 |
| --- | --- |
| 사무라이가 주인공인 벨트스크롤 액션 | 가상의 일본풍 섬, 주인공 이름 미정 |
| 첫 마을에서 반격하여 점령지를 되찾음 | 1챕터는 농촌·창고 마을·고개 초소 3거점 |
| 전체 5챕터, 클리어마다 전투 NPC 해금 | 총 5명 수집, 동시 출정은 선택한 1명 |
| 마을 관리로 점차 강해짐 | 관리도·군자금, 훈련장/보급창의 영구 효과 |
| 캐릭터당 액티브 8개 방향 | 조작 캐릭터는 1명, 이번에는 기존 2개 구현 유지 |
| 반응성은 좋지만 모멘텀 개선 필요 | 평타 전진·타별 동작·감속하는 피격 밀림을 함께 조절 |

거점 수, 동료 이름, 동시 출정 1명, 전투 수치는 기획 초기안이며 사용자 확정 사실로 취급하지 않는다. HWR 작업 번호와 저장소명은 이력 연결을 위해 유지한다.

## 2. 게임이 주는 경험
플레이어는 작은 저항의 거점을 살리고 전투를 통해 섬의 길과 자원을 하나씩 되찾는다. 전투에서 검이 몸과 함께 나가고, 전투 밖에서는 되찾은 마을이 실제로 회복되는 모습을 보여준다.
핵심 반복은 출정 → 전투 승리 → 마을 해방 → 복구/시설 선택 → 다음 거점이다. 챕터 마지막 승리는 지도 전선 변화와 새 동료의 합류로 크게 보상한다.
전체 캠페인은 반복 가능한 거점 전투를 기반으로 한다. 자유 이동 오픈월드나 다수 병력 지휘는 현재 구조에 포함하지 않는다.

## 3. 세계와 이야기
가상의 중세 일본풍 섬이 침략군의 점령하에 놓인다. 조직적인 방어가 무너진 뒤, 살아남은 사무라이가 농촌의 강제 징발을 막으며 첫 반격에 나선다. 섬의 보급로와 거점을 되찾아 최종적으로 항구의 점령군을 몰아낸다.
고스트 오브 쓰시마에서 참고하는 것은 점령지의 저항전, 고립된 무사, 되찾아가는 고향의 분위기다. 구체 인물·사건·대사·지도·문장은 이 프로젝트의 창작으로 구성한다. 현재 세계관은 역사 고증 완료를 표방하지 않는다.
주인공은 처음 혼자 싸우는 유일한 조작 캐릭터다. 일반 주민은 농사·운송·수리·피난민 돌봄을 맡는다. 이 역할도 반격을 지속시키는 기반으로 표현한다. 몇 명의 전문 전투원이 지역을 지킬 책임을 해결한 뒤 동료로 합류한다.
동료가 끝에서 갑자기 나타나지 않도록 해당 챕터 초중반의 짧은 장면에서 먼저 소개한다. 초반 소개는 대사/초상과 역할 설명으로 충분하며 그때부터 전투 AI가 필요한 것은 아니다.

## 4. 5챕터의 인과관계
각 챕터는 서로 다른 전선 문제를 해결한다. 아래 이름·상세 거점은 창작 작업안이며, 챕터 2~5는 이번에 콘텐츠를 제작하지 않는다.

| 챕터 | 해결할 문제와 전투의 차이 | 승리 후 마을의 변화 | 클리어 동료와 합류 이유 |
| --- | --- | --- | --- |
| 1 꺼진 봉화 | 농촌 징발대 제거 → 창고 확보 → 고개 초소 탈환. 기존 근접 전투와 대장 대응 | 논밭 복구, 창고 지붕 수리, 처음으로 봉화가 켜짐 | 궁수 아야. 초반에 주민을 피신시키던 인물; 길이 안전해진 뒤 합류 |
| 2 끊어진 길 | 나루와 교량을 장악한 병력 격퇴. 원거리 공격·깊이 이동 대응 | 마을 사이 운송로가 연결됨 | 창병 겐. 나루의 피난 행렬을 지키다 교량 확보 후 합류 |
| 3 굶주린 들판 | 군량 독점 세력의 수로·곡창 탈환. 방패 적과 후방 사수의 조합 | 물길과 식량 배급이 회복됨 | 검객 렌. 곡창 주민을 지키던 무사, 식량 위협 해소 후 합류 |
| 4 포위된 성 | 대장간과 성하를 거쳐 산성 돌파. 방어 진형·강공격 빈틈 공략 | 수리·장비 생산과 성내 피난처가 회복됨 | 수비 무사 토마. 성의 잔류 주민을 구출한 뒤 합류 |
| 5 마지막 물결 | 해안·조선 마을·군항 탈환. 이전 대응을 섞은 최종 지휘관 | 항구 개방, 섬의 점령 상태 해제 | 유랑 무사 시노. 포로선의 주민을 구출하고 귀환한 뒤 합류 |

초안의 챕터당 3거점, 총 15거점은 분량 기준안이다. 반복성이 크면 후속 기획에서 조절하되 5챕터와 5회 동료 해금은 유지한다.
챕터 5 동료는 엔딩 후 기존 거점 재도전에서 사용할 수 있다. 별도 6챕터나 무한 던전은 필요하지 않다. 해금 동료가 기존 동료보다 무조건 강해지는 상위 교체품이 되지 않도록 역할을 다르게 한다.

## 5. 전투와 성장
반응이 좋았던 M1의 지상 이동, 평타 준비/타격/회복 시간, 입력 보관, 회피, 깊이·높이 판정을 출발점으로 한다.
모멘텀은 공격의 전진, 몸/검의 연결, 맞은 적의 충격·감속을 같은 시간축에서 맞춘다. 이동 전체에 긴 관성을 추가하지 않는다. 물리 래그돌이 아니라 수치를 통제할 수 있는 동작으로 만든다. 상세 수치와 비교 방법은 전투 감각 문서가 기준이다.

### 액티브 8개 계획
기존 리소스 ID와 파일 경로는 유지하고 화면 표시명을 바꾼다. 아래 역할은 유지하되 이번에는 앞의 2개만 작동한다.

| 키 | 표시명 초안 | 역할 | HWR-002 R1 |
| --- | --- | --- | --- |
| A | 돌진베기 | 접근·전방 베기 | 기존 구현 유지 |
| S | 올려베기 | 띄우기·공중 적 연결 | 기존 구현 유지 |
| D | 내려베기 | 강한 마무리·다운 | 후속 구현 |
| F | 회전베기 | 가까운 양쪽 견제 | 후속 구현 |
| Q | 방어깨기 | 정면 방어 대응 | 후속 구현 |
| W | 검기 | 깊이를 맞춘 원거리 견제 | 후속 구현 |
| E | 흘려받기 | 짧은 방어·반격 | 후속 구현 |
| R | 일섬연무 | 긴 재사용 시간의 연속 마무리 | 후속 구현 |

기술 연출은 절제된 판타지 초기안이다. 모멘텀 요구를 모든 초현실적 기술 금지로 확대 해석하지 않는다. 평타/회피/점프는 액티브 8개에 포함하지 않는다. NPC는 이번에는 기본 공격 중심의 지원 AI이며 조작 캐릭터의 8스킬을 복제하지 않는다.

## 6. 이번에 완주할 범위
HWR-002 R1은 5챕터 전체의 완성이 아니라 아래 첫 챕터를 끝까지 연결하는 작업이다. 이것은 초안과 같은 구현 범위이며, 내부 단계를 나누어 검증한다.

| 단계 | 플레이 결과 |
| --- | --- |
| A 전투 감각 | 수련장에서 기존/새 모멘텀을 비교하며 평타를 확인 |
| B 첫 마을 | 지도 → 농촌 전투 → 해방 → 정비 → 훈련장 선택 → 저장 후 복원 |
| C 첫 챕터 | 창고 마을과 고개 초소 추가 → 챕터 클리어 → 궁수 합류 |
| D 동료 재도전 | 동료 선택/해제 → 해방 거점 재도전 → 궁수 실제 공격·피격·이탈 확인 |

이 단계들은 같은 작업의 내부 검증 순서다. 단계마다 커밋과 실행 확인을 남기고, 새 승인 없이 순서대로 완료한다. 통과하지 못한 단계를 완료로 기록하지 않는다.
첫 챕터 목표 플레이 시간은 관리·첫 안내 포함 약 5~10분이며 실제 플레이로 조정한다. 자동 검증 통과는 손맛이나 플레이 시간을 보증하지 않는다.
마을마다 별도 자유 이동 마을 장면을 만들 필요는 없다. 지도와 통일된 관리 화면의 전경·시설 상태 변화로 정복과 복구를 보여준다.

## 7. 화면 흐름과 개발 범위
시작 화면: 새 게임 / 이어하기 / 수련장. 새 게임은 기존 저장이 있을 때만 덮어쓰기 확인을 한다.
지도: 5개 챕터와 현재 거점, 해방 상태, 다음 개방 조건. 챕터 2~5는 콘텐츠 준비 중 표시이며 조건 충족을 이유로 미구현 전투에 진입하지 않는다.
관리: 해당 마을의 전경, 관리도, 군자금, 시설 비용과 효과, 다음 거점 조건. 기능 이름과 비용을 한 번에 알 수 있게 한다.
전투: 기존 조작, 주인공/동료 체력, 스킬, 적 등장 상태, 보스 예고, 승패 결과. 디버그는 수련장 중심으로 숨길 수 있다.
캠페인에서는 적 재생성·주인공 초기화로 보상을 반복 획득할 수 없게 한다. 수련장은 캠페인 보상/저장과 분리한다.

## 8. 이후 순서
첫 챕터를 플레이한 뒤 모멘텀, 관리의 이해도, 동료 존재감을 평가한다. 그다음 나머지 6스킬과 챕터 2의 적 대응을 함께 확장한다.
챕터 3~5, 나머지 동료 AI 4명, 최종 미술, 농업 시뮬레이션, 멀티플레이는 이번 작업 밖이다. 잠긴 동료의 설명·데이터 자리만 마련하고 미구현 동작을 사용 가능하게 표시하지 않는다.

## 9. 문서 간 적용 규칙
최신 사용자 요청 → 이 문서와 연결된 상세 규칙 → HWR-002 R1 구현 지시를 함께 적용한다. 구체 수치나 인수 조건은 상세 문서가 기준이다. 서로 충돌하면 작업 보고에 명시하고 임의로 범위를 확대하지 않는다.
v0.2와 이전 handoff는 기록으로 보존한다. 이전 문서의 군사 초소 관리도/정비, 시설이 없는 창고, 모멘텀 방식의 모호한 부분은 R1에서 아래 상세 문서로 바꿨다.
