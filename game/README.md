# 화랑전 전투 실험 (Godot 프로젝트)

HWR-001 에서 만든 M0·M1 전투 실험 프로젝트다. 임시 도형으로 표현한 화랑 1명이 평평한 전투 공간에서
이동·점프·회피·평타 3연격·비연참·승월참을 사용하고, 허수아비와 근접 적으로 타격·피격을 확인한다.

## 엔진 버전

- **Godot 4.7.2 stable** (공식 빌드 `4.7.2.stable.official.ed1daf0bf`), GDScript, GL Compatibility 렌더러.
- 프로젝트 파일의 `config/features` 가 4.7 로 고정되어 있다. 개발 중 자동으로 올리지 않는다.
- 4.7.x 이후 버전으로 열면 변환 안내가 뜰 수 있다. 4.4 이하에서는 열지 않는다.

## 실행 방법

### 에디터에서

1. Godot 4.7.2 를 받아 실행한다. https://godotengine.org/download
2. 프로젝트 관리자에서 **가져오기(Import)** → 이 폴더의 `project.godot` 선택 → 편집기 열기.
3. **F5**(프로젝트 실행)를 누른다. 메인 장면은 `scenes/battle.tscn` 이다.

### 명령줄에서

```bash
# 프로젝트 폴더에서 (godot = 4.7.2 실행 파일)
godot --path . 
```

첫 실행이나 새 클론 직후에는 리소스 가져오기가 필요하다. 에디터로 한 번 열거나 아래를 먼저 실행한다.

```bash
godot --headless --path . --import
```

## 조작

| 키 | 동작 |
| --- | --- |
| 방향키 | 지상 이동 (좌우 x, 깊이 y). 대각선은 정규화 뒤 축별 속도 적용 |
| X | 평타 3연격 (베기 → 역베기 → 마무리 베기). 공중에서는 공중 베기 1회 |
| C | 점프 (높이 z) |
| Space | 회피 (입력 방향 또는 바라보는 방향) |
| A | 비연참 — 바라보는 방향으로 짧게 돌진하며 벤다 (재사용 4초, 120%) |
| S | 승월참 — 아래에서 위로 베어 일반 적을 짧게 띄운다 (재사용 6초, 150%) |
| D F Q W E R | 미구현 (HUD 에 회색 "미구현" 으로 표시되고 입력은 무시된다) |
| Esc | 일시정지 |

### 개발용 키

| 키 | 동작 |
| --- | --- |
| F1 | 개발 표시 켜기/끄기 (바닥 위치, 높이, 피격·공격 범위, 현재 행동, 대기시간, 틱 양자화 적용값) |
| F5 | 허수아비와 근접 적 다시 생성 |
| F6 | 화랑 위치·체력·대기시간 초기화 |
| F12 | 스크린샷을 `user://screenshot_<ms>.png` 에 저장 (Linux: `~/.local/share/godot/app_userdata/화랑전 전투 실험 (HWR-001)/`) |

개발 표시 색: 초록 = 피격 발자국(바닥 x·깊이), 하늘색 = 피격 높이 상자, 빨강 = 공격 바닥 범위, 분홍 = 공격 높이 범위, 노랑 선 = 현재 높이 z.

## 자동 검증

헤드리스로 전투 규칙을 확인한다. 실패가 있으면 종료 코드 1.

```bash
godot --headless --path . -s tests/run_tests.gd
```

확인 항목: 틱 양자화, 대각선 이동 정규화·가감속, 깊이 불일치 시 빗나감, 높이 불일치 시 빗나감,
한 타 1회 적중, 다수 적중 시 타격 정지 비합산, 연결창에서의 선입력 연결, 만료 입력 미발동,
미구현 스킬 무시, 스킬 재사용 대기, 띄우기 1회 규칙, 회피 무적·재사용, 타격 정지 중 입력 수집,
사망 시 보관 입력 제거, 근접 적 순환과 예고 시 방향 고정, 평타 1세트로 근접 적 처치.

### 자동 시연과 스크린샷 (검증 기록용)

```bash
godot --path . -- --demo --screenshot=/tmp/battle.png
```

스크립트 입력(이동 → 평타 3연격 → 승월참)을 재생한 뒤 스크린샷을 저장하고 종료한다.

## 수치 조정

모든 수치는 에디터에서 리소스를 열어 고친다. 실행 중 상태(남은 틱, 체력)는 코드에 있고 정의 데이터와 분리된다.

| 파일 | 내용 |
| --- | --- |
| `data/combat_tuning.tres` | 이동 속도, 가감속, 입력 보관, 타격 정지, 회피, 점프, 플레이어·적 기본 수치 |
| `data/attacks/*.tres` | 평타 3타·공중 베기·비연참·승월참의 준비/타격/회복(ms), 피해 계수, 판정 범위(앞뒤 도달, 깊이 허용, 높이 범위), 연결창, 밀림, 띄우기 |
| `data/skills/*.tres` | 스킬 8칸: 이름, 키, 재사용, 구현 여부, 연결된 공격 데이터 |
| `data/hwarang_skills.tres` | 슬롯 순서 (A S D F Q W E R) |

ms 값은 60틱 고정 시뮬레이션에 맞춰 반올림된다. 적용값은 개발 표시(F1) 패널에 나온다.

| 항목 | 기획값 | 적용값 |
| --- | --- | --- |
| 입력 보관 | 120 ms | 7틱 = 116.7 ms (타격 정지 중에는 흐르지 않음) |
| 타격 정지 일반 / 강공격 | 35 / 60 ms | 2틱 = 33.3 ms / 4틱 = 66.7 ms |
| 회피 이동 / 무적 / 재사용 | 180 / 100 / 900 ms | 11틱 = 183.3 / 6틱 = 100 / 54틱 = 900 ms |
| 평타 연결창 | 마지막 100 ms | 6틱 = 100 ms |
| 스킬 이동·회피 취소 | 회복 마지막 100 ms | 6틱 |
| 비연참 / 승월참 재사용 | 4 / 6 초 | 240 / 360 틱 |

## 구조

| 경로 | 역할 (기획서 9장 대응) |
| --- | --- |
| `scripts/battle.gd` | 장면 컨트롤러 + CombatResolver: 틱 순서, 적중 판정(좌우·깊이·높이), 중복 적중 방지, 개발용 동작 |
| `scripts/core/battle_actor.gd` | 모든 개체의 바탕: 바닥 (x, y) 와 높이 z 분리, 그림자·Y 정렬, 타격 정지, 무적, 피격 범위 |
| `scripts/core/hit_box.gd`, `hit_info.gd` | 공격 인스턴스별 판정과 적용 기록 |
| `scripts/core/player_input.gd` | 한 틱의 입력 (실제 입력 또는 테스트 입력) |
| `scripts/actors/player.gd` | PlayerController + ActionState + SkillSystem: 입력 보관, 이동, 점프, 회피, 평타 연결, 스킬 실행·대기 |
| `scripts/actors/enemy_base.gd` | 적 공통 피격 반응: 경직, 띄우기 1회, 다운, 기상 보호 |
| `scripts/actors/dummy.gd`, `melee_enemy.gd` | 허수아비, 근접 적 (접근 → 예고 → 공격 → 회복) |
| `scripts/data/*.gd` | Resource 정의: AttackData, SkillData, SkillSet, CombatTuning |
| `scripts/ui/hud.gd`, `debug_overlay.gd` | 전투 정보와 개발 표시 |
| `scripts/core/arena.gd` | 바닥·벽 그리기 (경계는 Battle.arena_rect) |
| `tests/run_tests.gd` | 헤드리스 자동 검증 |
| `assets/fonts/GothicA1-Regular.ttf` | 한글 표시용 글꼴 (SIL OFL 1.1, `OFL.txt` 동봉) |
