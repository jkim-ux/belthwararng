# 사무라이 점령전 (Godot 프로젝트)

HWR-001 의 M0·M1 전투 실험 위에 HWR-002 R1(마을·동료·저장), HWR-003(방 던전·원거리 적), HWR-004 R1(적 피해 2배·강인병·액티브 8개), HWR-005(직접 가꾸는 마을), HWR-006(바람 정령 마을·측면 카툰 3D)를 얹은 프로젝트다.
임시 도형으로 표현한 사무라이 1명이 평평한 전투 공간에서 이동·점프·회피·평타 3연격·돌진베기·올려베기를 쓰고,
첫 챕터 3거점(농촌 → 창고 마을 → 고개 초소)을 각각 **입구 → 일반 전투방 3개(2웨이브) → 보스방**의 던전으로 공략한다.
선택 보물방 1개, 근접병·궁수·화염 투척병, 우측 상단 방 미니맵이 있으며 보스를 처치해야 거점이 해방된다.
해방한 농촌/창고는 16×12 논리 격자 마을로 직접 걸어 들어가 건물 배치·관개·정령(주민) 배정으로 가꾼다(HWR-005). HWR-006 부터 마을은 낮은 측면(벨트스크롤) 시점의 단순 카툰 3D 로 보이고,
밭 정돈·공사·농사·생산은 흰 오목눈이 모습의 바람 정령에게 부탁해 진행한다(플레이어 직접 작업 없음).

## 엔진 버전

- **Godot 4.7.2 stable** (공식 빌드 `4.7.2.stable.official.ed1daf0bf`), GDScript, GL Compatibility 렌더러.
- 프로젝트 파일의 `config/features` 가 4.7 로 고정되어 있다. 개발 중 자동으로 올리지 않는다.
- 4.7.x 이후 버전으로 열면 변환 안내가 뜰 수 있다. 4.4 이하에서는 열지 않는다.

## 실행 방법

### 에디터에서

1. Godot 4.7.2 를 받아 실행한다. https://godotengine.org/download
2. 프로젝트 관리자에서 **가져오기(Import)** → 이 폴더의 `project.godot` 선택 → 편집기 열기.
3. **F5**(프로젝트 실행)를 누른다. 메인 장면은 `scenes/main.tscn`(시작 화면)이다. `scenes/battle.tscn` 을 직접 실행하면 수련장만 뜬다.
4. 전투 없이 마을을 확인하려면 **마을 바로 테스트 (전투 없이 · 별도 저장)**를 누른다. 첫 농촌과 정령 3명, 건설용 물자가 준비된다. 배치 내용은 별도 테스트 슬롯에 이어서 저장되고 **테스트 종료**로 시작 화면에 돌아온다.

테스트 마을은 일반 저장 경로 뒤에 `.village_test`를 붙인 슬롯을 사용한다. 기본값은 `user://campaign_save.json.village_test`이며, 실제 캠페인의 해방·보상·저장에는 영향을 주지 않는다. 재진입 시 기존 테스트 배치를 불러오며 물자를 다시 지급하지 않는다.

### 명령줄에서

```bash
# 프로젝트 폴더에서 (godot = 4.7.2 실행 파일)
godot --path .                    # 시작 화면
godot --path . -- --training      # 수련장 바로 시작
godot --path . -- --village-test  # 전투 없이 마을 테스트로 바로 시작
godot --path . -- --save=user://other.json   # 다른 저장 파일 사용(테스트용)
```

첫 실행이나 새 클론 직후에는 리소스 가져오기가 필요하다. 에디터로 한 번 열거나 아래를 먼저 실행한다.

```bash
godot --headless --path . --import
```

## 화면 흐름 (캠페인)

시작 화면 **새 게임 / 이어하기 / 수련장** → **지도**(5챕터, 거점 상태, 진입 조건) → 거점 **출정** → **던전(방 이동)** → 보스 처치 → **결과 창** →
(마을이면) **마을 들어가기** → 마을 장면에서 건설·경로 복구 현장 완공(관리도 60) → 다음 거점. 초소 보스 최초 격파 → 챕터 1 클리어 → **합류 장면** → **동료 선택** → 지도.

테스트 전용: 시작 화면 **마을 바로 테스트** → **농촌 마을** → **테스트 종료** → 시작 화면.

### 마을 (HWR-005 규칙 + HWR-006 정령·측면 3D)

- 지도의 **마을 들어가기**로 해방된 농촌/창고에 들어간다. 출입구(남쪽 '출구' 칸)에서 **E** 또는 상단 **지도로** 버튼으로 나온다. 초소는 군사 거점이라 마을이 없다.
- 시점(HWR-006): 마을 표시 영역(상단 44px·하단 96px 제외)에 SubViewport 의 직교 Camera3D 가 수평에서 20도 내려다본다(방위 회전 없음). 논리 칸 (qx,qy) → 3D 바닥 (2.0·qx, 0, 0.9·qy) 로 가로를 넓히고 깊이를 압축해
  직교 크기 8.5(기존 12 대비 정령 약 1.41배 확대), 한 화면에 약 9.4칸이 보이며 카메라는 가로만 따라간다. **M** 전체 보기는 각도를 유지하고 줌만 바꾼다. 48px 논리 좌표와 건물 ID는 유지하며, 기존 저장의 배치 위치는 작은 마을에 맞게 이전한다.
- 이동 속도는 화면 기준 가로 약 300px/s · 깊이 약 105px/s 를 논리 칸 속도로 환산한다(대각선 정규화, 통행 판정은 논리 격자).
- 마우스 → 칸: 루트 Viewport 위치 → 표시 TextureRect 안 위치 → SubViewport 픽셀 → Camera3D 레이 → Y=0 바닥 평면 교차 → 역변환 → floor. 화면 밖/교차 실패는 배치 불가. 자유 모드 클릭은 보이는 건물 메시 영역으로 선택하고 겹치면 같은 자리를 다시 눌러 뒤쪽을 순환 선택한다.
  조작 대상(플레이어·E 대상·미리보기 칸)을 덮는 앞쪽 건물만 옅게 그린다.
- 자원: 군자금(전투 보상)·**목재**(벌목소)·**석재**(채석장)·**식량**(농장 수확)은 해방 마을이 공유한다. 주민·건물 배치는 마을별이다.
  첫 농촌 진입 때 한 번 목재 60/석재 40/식량 20 을 받는다(재입장·로드·재승리로 다시 주지 않음).
- 시작 마을은 **16×12칸**(기존 가로·세로의 절반, 면적 ¼). 덤불·개간 장애물 없이 빈 땅에 바로 건설한다. 농장에 비옥토 조건은 없으며 물·정령 조건은 유지한다.
- 실제 3D 배경: 풀밭·둥근 나무·겹친 낮은 언덕·나무 울타리·작은 꽃. 배경 소품은 건설과 통행을 막지 않는다.
- 옛 32×24 저장은 한 번만 작은 마을로 재배치한다. 원본 `.large-village.bak` 및 이전 배치 기록을 남기고, 공간이 부족한 건물은 ID·완공 상태·진행량을 보관한다. 건설 목록에 **보관 N · 무료 재배치**가 표시되며 같은 버튼으로 되놓을 수 있다. 자원과 시설 효과는 유지한다. 물길은 새 배치에 맞게 다시 연결해야 할 수 있다.
- 건설: 하단 목록(**B**)에서 고르면 반투명 건물 + 점유 바닥 + 작업 위치(문) 미리보기가 마우스를 따라온다. **좌클릭** 확정(이때 비용 차감), **R** 회전, **우클릭/Esc** 취소. 불가 이유(강 위·통로 막힘·목재 8 부족 …)를 ✓/× 와 함께 보여준다.
  확정하면 공사 현장이 놓이고 정령을 배정해야 **공사**가 진행된다(정령 초당 5. 플레이어 직접 공사·농사는 HWR-006 에서 제거). 공사 취소는 100% 반환, 완공 건물 이동은 무료(ID·진행·주민 유지), 철거는 원재료 반환.
- 수로는 **드래그**로 여러 칸을 미리 보고 한 번에 확정한다(전부 설치 또는 전부 취소). 길은 무료·즉시 완공.

| 건물 | 크기 | 비용(군자금/목재/석재) | 공사량 | 기능 |
| --- | --- | --- | --- | --- |
| 농장 | 3×3 | 0/10/2 | 30 | 빈 일반 땅 어디든(잎사귀 텃밭). 물 + 농부 정령 1명으로 30초에 식량 6. 씨앗 → 싹 → 익은 작물 → 바구니 3단계 표시 |
| 우물 | 2×2 | 0/8/6 | 30 | 연결 농장 2개 공급 |
| 수로 | 1×1 | 0/1/0 | 5 | 상하좌우 연결. 대각선 없음 |
| 작은 보 | 3×2 | 30/20/20 | 60 | 마을당 강가 자리 1곳. 육지 출구에서 농장 4개 공급 |
| 벌목소 / 채석장 | 2×2 | 0/12/2 · 0/8/8 | 30 | 숲/암반 작업 구역에 접해야 함. 주민 1명, 20초에 목재 6 / 석재 4. 주기 시작에 식량 1 소비, 없으면 절반(3/2) |
| 주택 | 2×2 | 0/10/4 | 30 | 완공 시 주민 2명 귀환(1회). 마을당 2채, 초기 3 → 최대 7 |
| 경로 복구 현장 | 고정 2×2 | 40/10/5 | 30 | 완공 시 관리도 40 → 60, 다음 거점 개방 |
| 훈련장 / 보급창 | 3×2 | 60/12/6 | 30 | 관리도 60 필요. 완공 시 공격력 +5% / 최대 체력 +10 (1회) |

- 물: 완공된 우물(점유 칸)·보(출구 칸)와 수로가 상하좌우로 이어진 연결망의 용량을 합산하고, 농장 생성 ID 순서로 1씩 배정한다. 부족한 농장은 '용수 부족'. **V** 관개 보기로 망·공급 수를 겹쳐 본다. 수로를 끊으면 먼 농장도 멈추고 진행량은 보존된다.
- 정령(주민): 건물 클릭 → 오른쪽 패널에서 배정. 한 정령은 한 작업(정돈·공사·농사·벌목·채석)만 하며 실제로 걸어가 도착한 뒤에 일한다. 공사·정돈 완료 후에는 빈손으로 돌아와 시작 칸 주변을 짧게 산책한다(반경 2칸, 배정하면 즉시 취소).
  화면 동작은 idle(호흡·깜박임·꼬리)/move(통통 뛰기)/windup(0.2초 모으기)/work(날개 펴고 곡선 바람 2~3줄 + 씨앗·물방울·잎)/harvest(이삭이 바구니로 모이고 짧게 기뻐함)/blocked(고개 갸웃 + 표식)/rest(앉아서 쉼 + 물방울 표식) 이며,
  길이 막히거나 물이 없으면 거짓 농사 연출 없이 이유가 보인다. 초기 정령 3명은 잎/푸른 매듭/짚 매듭 액세서리로 구분되며 능력은 같다.
- 경제 시간은 **지금 들어가 있는 마을에서만** 10Hz 고정 틱으로 흐른다. 지도·전투·다른 마을·앱을 닫은 동안에는 생산과 공사가 멈춘다(오프라인 생산 없음). 완료 이벤트는 즉시, 중간 진행은 10초마다 저장한다.

### 거점 던전 (HWR-003)

| 방 | 격자 | 내용 |
| --- | --- | --- |
| 입구 | (0,1) | 안전. 동쪽 문 → 전투 1 |
| 전투 1 | (1,1) | 2웨이브. 정리 전 문 잠김 |
| 전투 2 (갈림길) | (2,1) | 2웨이브. 북쪽 문 → 보물방(선택), 동쪽 문 → 전투 3 |
| 보물방 | (2,0) | 안전. 상자 1개: 생존 아군 최대 체력 20% 회복 + 군자금 30 보류(보스 승리 시 획득). 출정당 1회 |
| 전투 3 (보스 전 경비) | (3,1) | 2웨이브 |
| 보스방 | (4,1) | 보스 1명(농촌 징발대장 450 / 창고 보급대장 550 / 초소 대장 600). 처치 = 거점 승리 |

- 문 앞(초록 구역)에서 지상 상태로 **Enter** 를 새로 누르면 이동한다(길게 눌러도 1회). 잠긴 문(빨강·자물쇠)은 적을 모두 처치해야 열린다.
- 일반 방: 진입 후 0.3초 전이 → 위치 예고 0.7초 → 1웨이브 → 전멸 후 1초 → 예고 → 2웨이브 → 전멸 시 방 정리·문 개방. 정리한 방은 재방문해도 적이 나오지 않는다.
- 방 이동은 주인공 체력, 스킬·회피 대기시간, 동료 체력·이탈을 그대로 유지한다. 새 출정에서만 체력·동료가 회복된다.
- 일반 방 정리는 보상·저장을 만들지 않는다. 보스 승리 시 기본 보상(최초 100 / 재도전 20)에 상자 30 을 한 번 합쳐 저장한다(개봉 시 130 / 50). 패배·포기는 보류 군자금도 사라진다.
- 우측 상단 **미니맵**: 현재 방(노란 테두리·점), 미방문(흐림), 정리 완료(초록 체크), 잠긴 문(빨간 선·자물쇠), 열린 문(초록 선), 보스 B, 보물방 ?(미방문) → 상자(방문) → 열린 상자(개봉).

| 화염 투척병 | 체력 60, 준비 0.65초(착탄 범위 표시) + 비행 0.5초, 간격 4초, 사거리 460 | 예고 범위를 벗어난다. 준비 중 타격하면 취소. 던진 항아리는 사망해도 착탄 |
| 바닥 불 | 반경 56×28, 4초, 발 위치가 안이고 높이 12 이하인 아군에게 0.5초마다 **6**(첫 피해도 0.5초 뒤, 4초 최대 8회 = 48). 겹쳐도 초당 12 이상 없음. 경직·밀림 없음, E 를 소모하지 않음 | 벗어나면 즉시 중단. 점프로 넘을 수 있음 |
| 보스(대장) | 피해 **24**. 표적과 깊이 ≤8 에서 |dx| ≤110 이면 베기, 80~300 이고 경로가 닿으면 돌진(둘 다 되면 베기 우선, 같은 패턴 2회 연속 뒤엔 교체). 회복 첫 0.3초에 뒤로 60px | 패턴 중엔 경직·피격 타격 정지 0(피해만). 대기·접근 중 평타/A/S/D/F/E 반격은 짧은 경직, Q/W/R 은 항상 피해만. 베기·돌진은 E 가능 |

궁수·투척병은 **원거리 허가 1개**를 공유하고(동시에 예고하지 않음), 활성 화염 + 비행 중 항아리는 방당 **최대 2개**다. 강인병도 근접 허가 2 에 포함된다.
강인병은 근접병 1명을 교체해 배치한다(총원 21/23/24 유지, 한 웨이브 최대 1명): 농촌 전투 1 없음(경직 튜토리얼) · 전투 2 1웨이브 1 · 전투 3 각 1 / 창고 각 방 2웨이브 1 / 초소 모든 웨이브 1. 첫 등장 때 짧은 안내가 한 번 나온다.

### 새 게임 → 초소 → 동료 재도전 순서

1. 새 게임 → 지도에서 **징발당한 농촌 출정** → 입구 → 전투 1~3 → 징발대장 격파(군자금 100, 관리도 40. 상자를 열었으면 130).
2. 농촌 **관리** → **정비(-40)** → 관리도 60 → 창고 마을 개방. 선택: **훈련장(-60)** → 공격력 +5%.
3. **창고 마을 출정** → 보급대장 격파(100) → 관리 → 정비(-40) → 초소 개방. 선택: **보급창(-60)** → 최대 체력 +10.
4. **고개 초소 출정** → 초소 대장(체력 600, 전방 베기/직선 돌진 교대) 격파 → 챕터 1 클리어, 궁수 아야 해금, 합류 장면.
5. **동료 선택** → 아야 선택 → **아야와 농촌 재도전**(또는 지도에서 출정) → 함께 전투, 보스 승리 시 +20(상자 개봉 시 +50).

전투 중 **Esc** 일시정지 → **출정 포기**(보상 없이 지도로). 패배도 보상 없이 지도로 돌아가며 이전 점령·시설·자금은 유지된다.
출정 중간 저장은 없다(종료 후 이어하기는 지도에서 시작). 캠페인에서는 F5/F6 재생성·초기화가 동작하지 않는다.

## 저장

- 위치: `user://campaign_save.json` (Linux: `~/.local/share/godot/app_userdata/사무라이 점령전 (HWR-002)/`). 백업 `.bak`, 임시 `.tmp`.
  HWR-003/HWR-004/HWR-005 에서도 프로젝트 이름(`config/name`)을 바꾸지 않아 기존 저장 폴더가 그대로 쓰인다. HWR-005 에서 저장 형식이 schema_version 2 로 올라가며 1 은 자동 이전한다(아래 참고). 8스킬은 저장과 무관하게 처음부터 쓸 수 있다(기존 저장에도 자동 적용).
- 흐름: 후보 상태 → 임시 파일 기록 → 다시 읽어 확인 → 이전 정상 저장을 `.bak` 으로 보존 → 교체 → 메모리 반영.
- 실패 시 기존 상태를 유지하고 결과 창에 **저장 재시도 / 이전 저장으로 돌아가기**를 제공한다. 재시도는 같은 후보에 대해 수행하며 보상을 다시 더하지 않는다.
- 손상된 주 저장은 `.bak` 으로 복구를 시도하고, 그것도 없으면 새 게임/취소를 제공한다. 상위 `schema_version` 은 읽지 않는다.
- **schema_version 2** (HWR-005) 필드: schema 1 의 `currency`, `sites{id: liberated, management, repaired}`, `facilities{id: true}`, `cleared_chapters[]`, `unlocked_companions[]`, `selected_companion_id`, `last_committed_run_id` 에
  `wood`, `stone`, `food`, `supplies_granted[]`(일회성 물자를 준 마을), `villages{site_id: {initialized, next_id, cleared[], clearing{}, buildings{id: {def_id, x, y, rot, state, work_done, progress, fed, house_returned}}, villagers{id: {name, job_kind, job_building, job_obstacle}}}}` 를 더했다.
  `job_obstacle`(HWR-006 정돈 부탁 대상 장애물 ID) 은 schema 2 안의 선택 필드로, 없는 저장은 "" 로 채우고 없는/이미 정돈된 대상은 로드 시 해제한다(형식 번호 변경 없음).
  공격력·최대 체력·진입 가능·물 연결·통행 격자·주민 위치/경로는 저장하지 않고 계산한다.
- schema 1 저장은 이어하기 때 2 로 이전한다: 해방 마을에 템플릿·주민 3명, 정비 완료 → 고정 복구 현장 완공, 구매 시설 → 예약 자리에 완공 배치(비용 없음, 효과 플래그 유지), 첫 농촌 물자 1회. 원본은 `campaign_save.json.v1.bak` 으로 보존하고 새 형식을 원자 저장한다. 새 형식 저장이 실패하면 원본이 그대로 남고 재시도할 수 있다.
- 마을에서는 배치/취소/철거/이동/배정/완료 이벤트마다 같은 후보 → 검증 → 저장 경로를 쓰고, 중간 진행은 10초마다 저장한다. 저장 실패 시 마을 시간과 추가 변경을 멈추고 재시도/이전 저장을 제공한다.

### AttackData 주요 항목

| 항목 | 의미 |
| --- | --- |
| `startup_ms / active_ms / recovery_ms` | 준비·타격·회복 (틱으로 반올림, 최소 1틱) |
| `advance_px` | 지상 평타 전진 총량. 타격 구간 동안 곡선으로 나누며 타격 정지 중에는 멈추고 취소·경계 시 남은 양을 버린다 |
| `knockback / knockback_ms` | 대상 밀림 총 거리와 기간. `knockback_ms` 0 이면 M1 방식 일정 속도 |
| `hitstun_ms` | 경직. 0 이면 피해만 주고 상태를 바꾸지 않는다(동료 화살) |
| `swing_style` | 0 기존 사각형, 1 가로, 2 역가로, 3 사선, 4 내려베기, 5 회전, 6 찌르기, 7 검기, 8 방어, 9 연무 |
| `parryable` | 적 공격을 E 로 막을 수 있는지(강인병 내려찍기 false) |
| `knockdown / guard_break / ignores_boss_flinch` | D 다운 / Q 강인병 무너짐 / Q·W·R 보스 무반응 |
| `lock_after_cancel / move_cancel_ms / dodge_cancel_ms` | 신규 스킬의 취소 창과 취소 뒤 남은 행동 제한 |
| `shape_ellipse / ellipse_rx / ellipse_ry` | 바닥 타원 판정(강인병 내려찍기) |
| `guard / counter_attack` | E 방어 창(startup_ms 동안)과 성공 반격 동작 |
| `multi_hits / multi_hit_interval_ms / multi_hit_active_ticks / knockback_last_hit_only` | R 다단히트 |
| `fires_projectile / projectile_*` | W 검기 투사체(속도·사거리·높이·판정·수명·관통 수) |
