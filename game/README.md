# 사무라이 점령전 (Godot 프로젝트)

HWR-001 의 M0·M1 전투 실험 위에 HWR-002 R1(마을·동료·저장), HWR-003(방 던전·원거리 적), HWR-005(직접 가꾸는 마을)를 얹은 프로젝트다.
임시 도형으로 표현한 사무라이 1명이 평평한 전투 공간에서 이동·점프·회피·평타 3연격·돌진베기·올려베기를 쓰고,
첫 챕터 3거점(농촌 → 창고 마을 → 고개 초소)을 각각 **입구 → 일반 전투방 3개(2웨이브) → 보스방**의 던전으로 공략한다.
선택 보물방 1개, 근접병·궁수·화염 투척병, 우측 상단 방 미니맵이 있으며 보스를 처치해야 거점이 해방된다.
해방한 농촌/창고는 32×24 격자 마을로 직접 걸어 들어가 개간·건물 배치·공사·관개·주민 배정으로 가꾼다(HWR-005).

## 엔진 버전

- **Godot 4.7.2 stable** (공식 빌드 `4.7.2.stable.official.ed1daf0bf`), GDScript, GL Compatibility 렌더러.
- 프로젝트 파일의 `config/features` 가 4.7 로 고정되어 있다. 개발 중 자동으로 올리지 않는다.
- 4.7.x 이후 버전으로 열면 변환 안내가 뜰 수 있다. 4.4 이하에서는 열지 않는다.

## 실행 방법

### 에디터에서

1. Godot 4.7.2 를 받아 실행한다. https://godotengine.org/download
2. 프로젝트 관리자에서 **가져오기(Import)** → 이 폴더의 `project.godot` 선택 → 편집기 열기.
3. **F5**(프로젝트 실행)를 누른다. 메인 장면은 `scenes/main.tscn`(시작 화면)이다. `scenes/battle.tscn` 을 직접 실행하면 수련장만 뜬다.

### 명령줄에서

```bash
# 프로젝트 폴더에서 (godot = 4.7.2 실행 파일)
godot --path .                    # 시작 화면
godot --path . -- --training      # 수련장 바로 시작
godot --path . -- --save=user://other.json   # 다른 저장 파일 사용(테스트용)
```

첫 실행이나 새 클론 직후에는 리소스 가져오기가 필요하다. 에디터로 한 번 열거나 아래를 먼저 실행한다.

```bash
godot --headless --path . --import
```

## 화면 흐름 (캠페인)

시작 화면 **새 게임 / 이어하기 / 수련장** → **지도**(5챕터, 거점 상태, 진입 조건) → 거점 **출정** → **던전(방 이동)** → 보스 처치 → **결과 창** →
(마을이면) **마을 들어가기** → 마을 장면에서 개간·건설·경로 복구 현장 완공(관리도 60) → 다음 거점. 초소 보스 최초 격파 → 챕터 1 클리어 → **합류 장면** → **동료 선택** → 지도.

### 마을 (HWR-005)

- 지도의 **마을 들어가기**로 해방된 농촌/창고에 들어간다. 출입구(남쪽 '출구' 칸)에서 **E** 또는 상단 **지도로** 버튼으로 나온다. 초소는 군사 거점이라 마을이 없다.
- 자원: 군자금(전투 보상)·**목재**(나무 개간, 벌목소)·**석재**(바위 개간, 채석장)·**식량**(농장 수확)은 해방 마을이 공유한다. 주민·건물·개간은 마을별이다.
  첫 농촌 진입 때 한 번 목재 60/석재 40/식량 20 을 받는다(재입장·로드·재승리로 다시 주지 않음).
- 개간: 덤불 1초(보상 없음)·작은 나무 2초(목재 4)·바위 3초(석재 3). 인접해서 **E** 를 누르는 동안 진행하며 놓아도 진행량은 남는다. 제거한 나무/바위는 되살아나지 않는다.
- 건설: 하단 목록(**B**)에서 고르면 반투명 미리보기가 마우스를 따라온다. **좌클릭** 확정(이때 비용 차감), **R** 회전, **우클릭/Esc** 취소. 불가 이유(강 위·덤불 제거 필요·통로 막힘·목재 8 부족 …)를 ✓/× 와 함께 보여준다.
  확정하면 자재 더미·기초가 놓이고 **공사**가 시작된다(플레이어 E 초당 5, 배정 주민 초당 1, 합산 가능). 공사 취소는 100% 반환, 완공 건물 이동은 무료(ID·진행·주민 유지), 철거는 원재료 반환.
- 수로는 **드래그**로 여러 칸을 미리 보고 한 번에 확정한다(전부 설치 또는 전부 취소). 길은 무료·즉시 완공.

| 건물 | 크기 | 비용(군자금/목재/석재) | 공사량 | 기능 |
| --- | --- | --- | --- | --- |
| 농장 | 3×3 | 0/10/2 | 30 | 비옥한 개간지. 물 + 농부 1명(또는 플레이어 E)으로 30초에 식량 6 |
| 우물 | 2×2 | 0/8/6 | 30 | 연결 농장 2개 공급 |
| 수로 | 1×1 | 0/1/0 | 5 | 상하좌우 연결. 대각선 없음 |
| 작은 보 | 3×2 | 30/20/20 | 60 | 마을당 강가 자리 1곳. 육지 출구에서 농장 4개 공급 |
| 벌목소 / 채석장 | 2×2 | 0/12/2 · 0/8/8 | 30 | 숲/암반 작업 구역에 접해야 함. 주민 1명, 20초에 목재 6 / 석재 4. 주기 시작에 식량 1 소비, 없으면 절반(3/2) |
| 주택 | 2×2 | 0/10/4 | 30 | 완공 시 주민 2명 귀환(1회). 마을당 2채, 초기 3 → 최대 7 |
| 경로 복구 현장 | 고정 2×2 | 40/10/5 | 30 | 완공 시 관리도 40 → 60, 다음 거점 개방 |
| 훈련장 / 보급창 | 3×2 | 60/12/6 | 30 | 관리도 60 필요. 완공 시 공격력 +5% / 최대 체력 +10 (1회) |

- 물: 완공된 우물(점유 칸)·보(출구 칸)와 수로가 상하좌우로 이어진 연결망의 용량을 합산하고, 농장 생성 ID 순서로 1씩 배정한다. 부족한 농장은 '용수 부족'. **V** 관개 보기로 망·공급 수를 겹쳐 본다. 수로를 끊으면 먼 농장도 멈추고 진행량은 보존된다.
- 주민: 건물 클릭 → 오른쪽 패널에서 배정. 한 주민은 한 작업만 하며 실제로 걸어가 도착한 뒤에 일한다. 공사 완료 후에는 빈손으로 돌아온다.
- 경제 시간은 **지금 들어가 있는 마을에서만** 10Hz 고정 틱으로 흐른다. 지도·전투·다른 마을·앱을 닫은 동안에는 생산과 공사가 멈춘다(오프라인 생산 없음). 완료 이벤트는 즉시, 중간 진행은 10초마다 저장한다.

### 거점 던전 (HWR-003)

| 방 | 격자 | 내용 |
| --- | --- | --- |
| 입구 | (0,1) | 안전. 동쪽 문 → 전투 1 |
| 전투 1 | (1,1) | 2웨이브. 정리 전 문 잠김 |
| 전투 2 (갈림길) | (2,1) | 2웨이브. 북쪽 문 → 보물방(선택), 동쪽 문 → 전투 3 |
| 보물방 | (2,0) | 안전. 상자 1개: 생존 아군 최대 체력 20% 회복 + 군자금 30 보류(보스 승리 시 획득). 출정당 1회 |
| 전투 3 (보스 전 경비) | (3,1) | 2웨이브 |
| 보스방 | (4,1) | 보스 1명(농촌 징발대장 450 / 창고 보급대장 550 / 초소 대장 600). 처치 = 거점 승리 |

- 문 앞(초록 구역)에서 지상 상태로 **Enter** 를 새로 누르면 이동한다(길게 눌러도 1회). 잠긴 문(빨강·자물쇠)은 적을 모두 처치해야 열린다.
- 일반 방: 진입 후 0.3초 전이 → 위치 예고 0.7초 → 1웨이브 → 전멸 후 1초 → 예고 → 2웨이브 → 전멸 시 방 정리·문 개방. 정리한 방은 재방문해도 적이 나오지 않는다.
- 방 이동은 주인공 체력, 스킬·회피 대기시간, 동료 체력·이탈을 그대로 유지한다. 새 출정에서만 체력·동료가 회복된다.
- 일반 방 정리는 보상·저장을 만들지 않는다. 보스 승리 시 기본 보상(최초 100 / 재도전 20)에 상자 30 을 한 번 합쳐 저장한다(개봉 시 130 / 50). 패배·포기는 보류 군자금도 사라진다.
- 우측 상단 **미니맵**: 현재 방(노란 테두리·점), 미방문(흐림), 정리 완료(초록 체크), 잠긴 문(빨간 선·자물쇠), 열린 문(초록 선), 보스 B, 보물방 ?(미방문) → 상자(방문) → 열린 상자(개봉).

### 적 3종

| 적 | 초기값 | 대응 |
| --- | --- | --- |
| 근접병 | 체력 65, 피해 10, 동시 공격 허가 최대 2 | 평타 경직·띄우기·회피 |
| 궁수 | 체력 55, 화살 8, 예고 0.65초(바닥 사격선, 방향·깊이 고정), 간격 2.2초, 사거리 560, 화살 650 px/s 높이 35 | 위아래로 깊이를 바꾸거나 점프·회피, 접근해 예고 중 타격(발사 취소) |
| 화염 투척병 | 체력 60, 준비 0.65초(착탄 범위 표시) + 비행 0.5초, 간격 4초, 사거리 460 | 예고 범위를 벗어난다. 준비 중 타격하면 취소. 던진 항아리는 사망해도 착탄 |
| 바닥 불 | 반경 56×28, 4초, 발 위치가 안이고 높이 12 이하인 아군에게 0.5초마다 3(첫 피해도 0.5초 뒤). 겹쳐도 초당 6 이상 없음. 경직·밀림 없음 | 벗어나면 즉시 중단. 점프로 넘을 수 있음 |

궁수·투척병은 **원거리 허가 1개**를 공유하고(동시에 예고하지 않음), 활성 화염 + 비행 중 항아리는 방당 **최대 2개**다.

### 새 게임 → 초소 → 동료 재도전 순서

1. 새 게임 → 지도에서 **징발당한 농촌 출정** → 입구 → 전투 1~3 → 징발대장 격파(군자금 100, 관리도 40. 상자를 열었으면 130).
2. 농촌 **관리** → **정비(-40)** → 관리도 60 → 창고 마을 개방. 선택: **훈련장(-60)** → 공격력 +5%.
3. **창고 마을 출정** → 보급대장 격파(100) → 관리 → 정비(-40) → 초소 개방. 선택: **보급창(-60)** → 최대 체력 +10.
4. **고개 초소 출정** → 초소 대장(체력 600, 전방 베기/직선 돌진 교대) 격파 → 챕터 1 클리어, 궁수 아야 해금, 합류 장면.
5. **동료 선택** → 아야 선택 → **아야와 농촌 재도전**(또는 지도에서 출정) → 함께 전투, 보스 승리 시 +20(상자 개봉 시 +50).

전투 중 **Esc** 일시정지 → **출정 포기**(보상 없이 지도로). 패배도 보상 없이 지도로 돌아가며 이전 점령·시설·자금은 유지된다.
출정 중간 저장은 없다(종료 후 이어하기는 지도에서 시작). 캠페인에서는 F5/F6 재생성·초기화가 동작하지 않는다.

### 수련장 개발용 키

| 키 | 동작 |
| --- | --- |
| F1 | 개발 표시 켜기/끄기 (바닥 위치, 높이, 피격·공격 범위, 현재 행동·구간, 전진량, 밀림 잔여량, 틱 양자화 적용값) |
| F2 | 프로필 전환: **기존 M1** ↔ **새 모멘텀 R1**. 행동이 끝난 상태(지상 대기)에서만 적용된다 |

### 수련장 A/B 비교법

1. 시작 화면 → 수련장. 기본은 **새 모멘텀 R1**(HUD 왼쪽 위 "프로필:" 줄).
2. 허수아비(700, 고정)와 **밀림 표적**(900, 밀림만 받음), 근접 적(1000)이 있다. 밀림 표적에 3연타를 넣어 밀림·연결을 본다.
3. F2 로 **기존 M1** 프로필로 바꾸고 같은 위치에서 같은 입력을 넣어 비교한다. 체력·피해·타이밍·시작 위치는 같다.
4. 프로필은 리소스 참조만 바꾸며 값을 수정하지 않는다. 캠페인은 항상 새 모멘텀이고 수련장은 저장을 건드리지 않는다.

| 항목 | 기존 M1 | 새 모멘텀 R1 |
| --- | --- | --- |
| 공격자 전진 (1/2/3타) | 0 / 0 / 0 px | 12 / 18 / 30 px, 타격 구간 동안 곡선 1-(1-u)² |
| 일반 적 밀림 | 30 / 30 / 70 px, 매초 240 px 일정 속도 | 12 / 18 / 65 px, 100 / 120 / 180 ms 감속 곡선 |
| 검 표시 | 앞쪽 사각형 | 가로 / 역가로 / 큰 사선 궤적 + 짧은 잔상, 몸 기울기(그림만) |
| 준비/타격/회복, 피해, 타격 정지 | 동일 | 동일 |

## 자동 검증

헤드리스로 규칙을 확인한다. 실패가 있으면 종료 코드 1.

```bash
godot --headless --path . -s tests/run_tests.gd            # 전투 규칙 (M1 회귀 + R1 모멘텀) 24개
godot --headless --path . -s tests/run_campaign_tests.gd   # 캠페인·저장·방 던전·원거리 적·화염·상자·보스·동료·화면 26개 (약 1~2분)
godot --headless --path . -s tests/run_village_tests.gd    # 마을(HWR-005) 정의·개간·배치·공사·물망·농사·생산·주민·진행·경제·schema1 이전·저장 실패·화면 15개 (약 1분)
```

캠페인 테스트는 `user://test_saves/` 아래 파일만 쓰고 지운다. 사용자 저장 `user://campaign_save.json` 은 건드리지 않는다.
캠페인 테스트 마지막에 3거점 × 2전략(가까운 적 우선 / 원거리 적 우선) 자동 플레이 측정값(방별 시간·받은 피해)을 출력한다.
이 값은 흐름 확인용이며 손맛·난이도 판단을 대신하지 않는다.

## 저장

- 위치: `user://campaign_save.json` (Linux: `~/.local/share/godot/app_userdata/사무라이 점령전 (HWR-002)/`). 백업 `.bak`, 임시 `.tmp`.
  HWR-005 에서도 프로젝트 이름(`config/name`)을 바꾸지 않아 기존 저장 폴더가 그대로 쓰인다.
- 흐름: 후보 상태 → 임시 파일 기록 → 다시 읽어 확인 → 이전 정상 저장을 `.bak` 으로 보존 → 교체 → 메모리 반영.
- 실패 시 기존 상태를 유지하고 결과 창에 **저장 재시도 / 이전 저장으로 돌아가기**를 제공한다. 재시도는 같은 후보에 대해 수행하며 보상을 다시 더하지 않는다.
- 손상된 주 저장은 `.bak` 으로 복구를 시도하고, 그것도 없으면 새 게임/취소를 제공한다. 상위 `schema_version` 은 읽지 않는다.
- **schema_version 2** (HWR-005) 필드: schema 1 의 `currency`, `sites{id: liberated, management, repaired}`, `facilities{id: true}`, `cleared_chapters[]`, `unlocked_companions[]`, `selected_companion_id`, `last_committed_run_id` 에
  `wood`, `stone`, `food`, `supplies_granted[]`(일회성 물자를 준 마을), `villages{site_id: {initialized, next_id, cleared[], clearing{}, buildings{id: {def_id, x, y, rot, state, work_done, progress, fed, house_returned}}, villagers{id: {name, job_kind, job_building}}}}` 를 더했다.
  공격력·최대 체력·진입 가능·물 연결·통행 격자·주민 위치/경로는 저장하지 않고 계산한다.
- schema 1 저장은 이어하기 때 2 로 이전한다: 해방 마을에 템플릿·주민 3명, 정비 완료 → 고정 복구 현장 완공, 구매 시설 → 예약 자리에 완공 배치(비용 없음, 효과 플래그 유지), 첫 농촌 물자 1회. 원본은 `campaign_save.json.v1.bak` 으로 보존하고 새 형식을 원자 저장한다. 새 형식 저장이 실패하면 원본이 그대로 남고 재시도할 수 있다.
- 마을에서는 배치/취소/철거/이동/배정/완료 이벤트마다 같은 후보 → 검증 → 저장 경로를 쓰고, 중간 진행은 10초마다 저장한다. 저장 실패 시 마을 시간과 추가 변경을 멈추고 재시도/이전 저장을 제공한다.

## 수치 조정

모든 수치는 에디터에서 리소스를 열어 고친다. 실행 중 상태(남은 틱, 체력, 진행한 전진량)는 코드에 있고 정의 데이터와 분리된다.

| 리소스 | 내용 |
| --- | --- |
| `data/combat_tuning.tres` | 이동 속도·가감속, 입력 보관, 타격 정지, 회피, 점프, 주인공/근접 적, 대장 기본값, 거점 전투(근접 허가 2·원거리 허가 1·화염 최대 2·웨이브 간격·전이), 적 궁수, 화염 투척병, 바닥 불 |
| `data/campaign/dungeons/*_dungeon.tres` | 거점별 6방 던전: 방 격자·연결·웨이브 구성과 출현 위치, 보스 이름·체력, 상자 회복 비율·군자금 |
| `data/attacks/light1~3.tres` | 기존 M1 평타 (전진 0, 밀림 30/30/70, 일정 속도) |
| `data/attacks/light1~3_r1.tres` | 새 평타 (전진 12/18/30, 밀림 12/18/65, 100/120/180 ms, 궤적 스타일) |
| `data/profiles/*.tres` | 수련장 비교 프로필 |
| `data/skills/*.tres`, `data/hwarang_skills.tres` | 액티브 8칸 (돌진베기·올려베기만 구현) |
| `data/campaign/campaign.tres` | 챕터 5개, 거점 3개(던전 참조·보상·시설), 동료 5명(아야만 구현) |

### AttackData 주요 항목

| 항목 | 의미 |
| --- | --- |
| `startup_ms / active_ms / recovery_ms` | 준비·타격·회복 (틱으로 반올림, 최소 1틱) |
| `advance_px` | 지상 평타 전진 총량. 타격 구간 동안 곡선으로 나누며 타격 정지 중에는 멈추고 취소·경계 시 남은 양을 버린다 |
| `knockback / knockback_ms` | 대상 밀림 총 거리와 기간. `knockback_ms` 0 이면 M1 방식 일정 속도 |
| `hitstun_ms` | 경직. 0 이면 피해만 주고 상태를 바꾸지 않는다(동료 화살) |
| `swing_style` | 0 기존 사각형, 1 가로, 2 역가로, 3 사선 |
