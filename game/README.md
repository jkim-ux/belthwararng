# 사무라이 점령전 (Godot 프로젝트)

HWR-001 의 M0·M1 전투 실험 위에 HWR-002 R1(마을·동료·저장), HWR-003(방 던전·원거리 적), HWR-004 R1(적 피해 2배·강인병·액티브 8개)을 얹은 프로젝트다.
임시 도형으로 표현한 사무라이 1명이 평평한 전투 공간에서 이동·점프·회피·평타 3연격·돌진베기·올려베기를 쓰고,
첫 챕터 3거점(농촌 → 창고 마을 → 고개 초소)을 각각 **입구 → 일반 전투방 3개(2웨이브) → 보스방**의 던전으로 공략한다.
선택 보물방 1개, 근접병·궁수·화염 투척병, 우측 상단 방 미니맵이 있으며 보스를 처치해야 거점이 해방된다.

## 엔진 버전

- **Godot 4.7.2 stable** (공식 빌드 `4.7.2.stable.official.ed1daf0bf`), GDScript, GL Compatibility 렌더러.
- 프로젝트 파일의 `config/features` 가 4.7 로 고정되어 있다. 개발 중 자동으로 올리지 않는다.
- 4.7.x 이후 버전으로 열면 변환 안내가 뜰 수 있다. 4.4 이하에서는 열지 않는다.

## 실행 방법

### 에디터에서

1. Godot 4.7.2 를 받아 실행한다. https://godotengine.org/download
2. 프로젝트 관리자에서 **가져오기(Import)** → 이 폴더의 `project.godot` 선택 → 편집기 열기.
3. **F5**(프로젝트 실행)를 누른다. 메인 장면은 `scenes/main.tscn`(시작 화면)이다. `scenes/battle.tscn` 을 직접 실행하면 수련장만 뜬다.

### 명령줄에서

```bash
# 프로젝트 폴더에서 (godot = 4.7.2 실행 파일)
godot --path .                    # 시작 화면
godot --path . -- --training      # 수련장 바로 시작
godot --path . -- --save=user://other.json   # 다른 저장 파일 사용(테스트용)
```

첫 실행이나 새 클론 직후에는 리소스 가져오기가 필요하다. 에디터로 한 번 열거나 아래를 먼저 실행한다.

```bash
godot --headless --path . --import
```

## 화면 흐름 (캠페인)

시작 화면 **새 게임 / 이어하기 / 수련장** → **지도**(5챕터, 거점 상태, 진입 조건) → 거점 **출정** → **던전(방 이동)** → 보스 처치 → **결과 창** →
(마을이면) **관리** 화면에서 정비·시설 → 다음 거점. 초소 보스 최초 격파 → 챕터 1 클리어 → **합류 장면** → **동료 선택** → 지도.

### 거점 던전 (HWR-003)

| 방 | 격자 | 내용 |
| --- | --- | --- |
| 입구 | (0,1) | 안전. 동쪽 문 → 전투 1 |
| 전투 1 | (1,1) | 2웨이브. 정리 전 문 잠김 |
| 전투 2 (갈림길) | (2,1) | 2웨이브. 북쪽 문 → 보물방(선택), 동쪽 문 → 전투 3 |
| 보물방 | (2,0) | 안전. 상자 1개: 생존 아군 최대 체력 20% 회복 + 군자금 30 보류(보스 승리 시 획득). 출정당 1회 |
| 전투 3 (보스 전 경비) | (3,1) | 2웨이브 |
| 보스방 | (4,1) | 보스 1명(농촌 징발대장 450 / 창고 보급대장 550 / 초소 대장 600). 처치 = 거점 승리 |

- 문 앞(초록 구역)에서 지상 상태로 **Enter** 를 새로 누르면 이동한다(길게 눌러도 1회). 잠긴 문(빨강·자물쇠)은 적을 모두 처치해야 열린다.
- 일반 방: 진입 후 0.3초 전이 → 위치 예고 0.7초 → 1웨이브 → 전멸 후 1초 → 예고 → 2웨이브 → 전멸 시 방 정리·문 개방. 정리한 방은 재방문해도 적이 나오지 않는다.
- 방 이동은 주인공 체력, 스킬·회피 대기시간, 동료 체력·이탈을 그대로 유지한다. 새 출정에서만 체력·동료가 회복된다.
- 일반 방 정리는 보상·저장을 만들지 않는다. 보스 승리 시 기본 보상(최초 100 / 재도전 20)에 상자 30 을 한 번 합쳐 저장한다(개봉 시 130 / 50). 패배·포기는 보류 군자금도 사라진다.
- 우측 상단 **미니맵**: 현재 방(노란 테두리·점), 미방문(흐림), 정리 완료(초록 체크), 잠긴 문(빨간 선·자물쇠), 열린 문(초록 선), 보스 B, 보물방 ?(미방문) → 상자(방문) → 열린 상자(개봉).

### 적 4종과 보스 (HWR-004 R1: 적 피해 2배)

| 적 | 초기값 | 대응 |
| --- | --- | --- |
| 근접병 | 체력 65, 피해 **20**, 동시 공격 허가 최대 2 | 평타 경직·띄우기·회피, 정면 베기는 E 로 흘려받기 |
| **강인병** | 체력 180, 피해 **24**/타, 이동 100/80, 큰 몸(반폭 32·반깊이 14·높이 94). 피해는 받지만 경직·밀림·띄우기·다운·피격 타격 정지가 없다 | **Q 방어깨기**만 1초 자세 무너짐(연장 없음). 2연격(준비 0.7초, 각 타 E 가능)은 막거나 피하고, 주변 내려찍기(준비 0.95초, 바닥 타원 110×45, 반격 불가)는 범위 밖으로 |
| 궁수 | 체력 55, 화살 **16**, 예고 0.65초(바닥 사격선, 방향·깊이 고정), 간격 2.2초, 사거리 560, 화살 650 px/s 높이 35 | 위아래로 깊이를 바꾸거나 점프·회피, 정면 화살은 E, 접근해 예고 중 타격(발사 취소) |
| 화염 투척병 | 체력 60, 준비 0.65초(착탄 범위 표시) + 비행 0.5초, 간격 4초, 사거리 460 | 예고 범위를 벗어난다. 준비 중 타격하면 취소. 던진 항아리는 사망해도 착탄 |
| 바닥 불 | 반경 56×28, 4초, 발 위치가 안이고 높이 12 이하인 아군에게 0.5초마다 **6**(첫 피해도 0.5초 뒤, 4초 최대 8회 = 48). 겹쳐도 초당 12 이상 없음. 경직·밀림 없음, E 를 소모하지 않음 | 벗어나면 즉시 중단. 점프로 넘을 수 있음 |
| 보스(대장) | 피해 **24**. 표적과 깊이 ≤8 에서 |dx| ≤110 이면 베기, 80~300 이고 경로가 닿으면 돌진(둘 다 되면 베기 우선, 같은 패턴 2회 연속 뒤엔 교체). 회복 첫 0.3초에 뒤로 60px | 패턴 중엔 경직·피격 타격 정지 0(피해만). 대기·접근 중 평타/A/S/D/F/E 반격은 짧은 경직, Q/W/R 은 항상 피해만. 베기·돌진은 E 가능 |

궁수·투척병은 **원거리 허가 1개**를 공유하고(동시에 예고하지 않음), 활성 화염 + 비행 중 항아리는 방당 **최대 2개**다. 강인병도 근접 허가 2 에 포함된다.
강인병은 근접병 1명을 교체해 배치한다(총원 21/23/24 유지, 한 웨이브 최대 1명): 농촌 전투 1 없음(경직 튜토리얼) · 전투 2 1웨이브 1 · 전투 3 각 1 / 창고 각 방 2웨이브 1 / 초소 모든 웨이브 1. 첫 등장 때 짧은 안내가 한 번 나온다.

### 새 게임 → 초소 → 동료 재도전 순서

1. 새 게임 → 지도에서 **징발당한 농촌 출정** → 입구 → 전투 1~3 → 징발대장 격파(군자금 100, 관리도 40. 상자를 열었으면 130).
2. 농촌 **관리** → **정비(-40)** → 관리도 60 → 창고 마을 개방. 선택: **훈련장(-60)** → 공격력 +5%.
3. **창고 마을 출정** → 보급대장 격파(100) → 관리 → 정비(-40) → 초소 개방. 선택: **보급창(-60)** → 최대 체력 +10.
4. **고개 초소 출정** → 초소 대장(체력 600, 전방 베기/직선 돌진 교대) 격파 → 챕터 1 클리어, 궁수 아야 해금, 합류 장면.
5. **동료 선택** → 아야 선택 → **아야와 농촌 재도전**(또는 지도에서 출정) → 함께 전투, 보스 승리 시 +20(상자 개봉 시 +50).

전투 중 **Esc** 일시정지 → **출정 포기**(보상 없이 지도로). 패배도 보상 없이 지도로 돌아가며 이전 점령·시설·자금은 유지된다.
출정 중간 저장은 없다(종료 후 이어하기는 지도에서 시작). 캠페인에서는 F5/F6 재생성·초기화가 동작하지 않는다.

| X | 평타 3연격 (가로베기 → 역가로베기 → 사선베기). 공중에서는 공중 베기 1회 |

| D | 내려베기 — 강한 단발(220%, 8초). 일반 지상 적 즉시 다운, 공중 적은 하강시켜 착지 후 다운. 앞 115·깊이 ±28·높이 -10~130. 9/5/16틱 |
| F | 회전베기 — 앞뒤 105·깊이 ±36 양쪽 견제(180%, 10초). 일반 적을 바깥으로 20px 밀며 300ms 경직. 5/5/14틱 |
| Q | 방어깨기 — 느린 강공격(300%, 12초). 일반 적 450ms 경직·35px, **강인병 1초 자세 무너짐**, 보스는 피해만. 15/6/21틱 |
| W | 검기 — 같은 깊이로 700 px/s·500px 관통 검기(160%, 7초). 최대 3명 대상당 1회, 아군·무적 통과. 6/3/12틱 |

모든 액티브는 지상 전용이다. D/F/Q/W 는 회복 마지막 100ms 에 이동/회피로 취소할 수 있지만 원래 종료 시점까지 평타·점프·스킬은 막힌다(후딜 우회 없음). 재사용은 시전 시작에 한 번 걸리고 취소·헛치기에도 돌려주지 않는다.
공격력 20 기준 피해: D 44 / F 36 / Q 60 / W 32 / E 반격 50 / R 20×5. 시설 공격력 21 이면 46 / 38 / 63 / 34 / 53 / 21×5(반올림).
| Enter | 문 이동 / 상자 열기 (캠페인, 문·상자 앞에서 지상 상태일 때. 새 누름만 인식) |
| Esc | 일시정지 (캠페인에서는 출정 포기 선택 가능) |
| 메뉴 | 마우스 클릭, 또는 방향키로 초점 이동 + Enter |

내부 ID 와 경로(`bieonchan`, `seungwolcham`, `hwarang_skills.tres` 등)는 HWR-001 과의 호환을 위해 유지하고 표시명만 바꿨다.

### 수련장 A/B 비교법

1. 시작 화면 → 수련장. 기본은 **새 모멘텀 R1**(HUD 왼쪽 위 "프로필:" 줄).
2. 허수아비(700, 고정)와 **밀림 표적**(900, 밀림만 받음), 근접 적(1000), **강인병**(1150, 실제로 접근·2패턴 공격)이 있다. 밀림 표적에 3연타를 넣어 밀림·연결을 보고, 강인병에는 평타가 통하지 않고 Q 만 무너뜨리는지 본다. 허수아비에 D/F/Q/W/R 피해를 확인한다.
3. F2 로 **기존 M1** 프로필로 바꾸고 같은 위치에서 같은 입력을 넣어 비교한다. 체력·피해·타이밍·시작 위치는 같다.
4. 프로필은 리소스 참조만 바꾸며 값을 수정하지 않는다. 캠페인은 항상 새 모멘텀이고 수련장은 저장을 건드리지 않는다.

| 공격자 전진 (1/2/3타) | 0 / 0 / 0 px | 12 / 18 / 30 px, 타격 구간 동안 곡선 1-(1-u)² |

## 자동 검증

헤드리스로 규칙을 확인한다. 실패가 있으면 종료 코드 1.

```bash
godot --headless --path . -s tests/run_tests.gd            # 전투 규칙 (M1 회귀 + R1 모멘텀 + HWR-004 강인병·보스·8스킬) 37개
godot --headless --path . -s tests/run_campaign_tests.gd   # 캠페인·저장·방 던전·원거리 적·화염·상자·보스·동료·화면·피해 2배·배치·전이 정리 29개 (약 2~3분)
godot --headless --path . -s tests/run_tests.gd -- --only=h4_skill   # 이름에 문자열이 들어간 테스트만
```

캠페인 테스트는 `user://test_saves/` 아래 파일만 쓰고 지운다. 사용자 저장 `user://campaign_save.json` 은 건드리지 않는다.
캠페인 테스트 마지막에 3거점 × 3전략(평타만 / 평타+A/S / 상황별 8스킬) 자동 플레이 측정값(방별 시간·받은 피해·강인병 공격 횟수·무너짐·방어·스킬 사용)을 출력한다.
이 값은 단순 자동 조작의 흐름 확인용이며 손맛·난이도 판단을 대신하지 않는다.

### 자동 시연과 스크린샷 (검증 기록용)

```bash
godot --path . -- --demo --screenshot=/tmp/battle.png
```

수련장에서 스크립트 입력(이동 → 평타 3연격)을 재생한 뒤 스크린샷을 저장하고 종료한다.

## 저장

- 위치: `user://campaign_save.json` (Linux: `~/.local/share/godot/app_userdata/사무라이 점령전 (HWR-002)/`). 백업 `.bak`, 임시 `.tmp`.
  HWR-003/HWR-004 에서도 프로젝트 이름(`config/name`)을 바꾸지 않아 기존 저장 폴더가 그대로 쓰인다. 저장 형식(schema_version 1)은 변경 없음. 8스킬은 저장과 무관하게 처음부터 쓸 수 있다(기존 저장에도 자동 적용).
- 흐름: 후보 상태 → 임시 파일 기록 → 다시 읽어 확인 → 이전 정상 저장을 `.bak` 으로 보존 → 교체 → 메모리 반영.
- 실패 시 기존 상태를 유지하고 결과 창에 **저장 재시도 / 이전 저장으로 돌아가기**를 제공한다. 재시도는 같은 후보에 대해 수행하며 보상을 다시 더하지 않는다.
- 손상된 주 저장은 `.bak` 으로 복구를 시도하고, 그것도 없으면 새 게임/취소를 제공한다. 상위 `schema_version` 은 읽지 않는다.
- schema_version 1 필드: `currency`, `sites{id: liberated, management, repaired}`, `facilities{id: true}`, `cleared_chapters[]`, `unlocked_companions[]`, `selected_companion_id`, `last_committed_run_id`. 공격력·최대 체력·진입 가능 여부는 저장하지 않고 계산한다.

## 수치 조정

모든 수치는 에디터에서 리소스를 열어 고친다. 실행 중 상태(남은 틱, 체력, 진행한 전진량)는 코드에 있고 정의 데이터와 분리된다.

| 리소스 | 내용 |
| --- | --- |
| `data/combat_tuning.tres` | 이동 속도·가감속, 입력 보관, 타격 정지, 회피, 점프, 주인공/근접 적(피해 20), 강인병(체력·피해·크기·2패턴 시간·무너짐), 대장(피해 24·거리 선택·회복 후퇴), 거점 전투(근접 허가 2·원거리 허가 1·화염 최대 2·웨이브 간격·전이), 적 궁수(화살 16), 화염 투척병, 바닥 불(6) |
| `data/campaign/dungeons/*_dungeon.tres` | 거점별 6방 던전: 방 격자·연결·웨이브 구성과 출현 위치, 보스 이름·체력, 상자 회복 비율·군자금 |
| `data/attacks/light1~3.tres` | 기존 M1 평타 (전진 0, 밀림 30/30/70, 일정 속도) |
| `data/attacks/light1~3_r1.tres` | 새 평타 (전진 12/18/30, 밀림 12/18/65, 100/120/180 ms, 궤적 스타일) |
| `data/profiles/*.tres` | 수련장 비교 프로필 |
| `data/skills/*.tres`, `data/hwarang_skills.tres` | 액티브 8칸(모두 구현). 각 스킬의 `attack` 은 `data/attacks/<id>.tres`(E 는 `yusubangyeok.tres` + 반격 `yusubangyeok_counter.tres`) |
| `data/campaign/campaign.tres` | 챕터 5개, 거점 3개(던전 참조·보상·시설), 동료 5명(아야만 구현) |

### AttackData 주요 항목

| 항목 | 의미 |
| --- | --- |
| `startup_ms / active_ms / recovery_ms` | 준비·타격·회복 (틱으로 반올림, 최소 1틱) |
| `advance_px` | 지상 평타 전진 총량. 타격 구간 동안 곡선으로 나누며 타격 정지 중에는 멈추고 취소·경계 시 남은 양을 버린다 |
| `knockback / knockback_ms` | 대상 밀림 총 거리와 기간. `knockback_ms` 0 이면 M1 방식 일정 속도 |
| `hitstun_ms` | 경직. 0 이면 피해만 주고 상태를 바꾸지 않는다(동료 화살) |
| `swing_style` | 0 기존 사각형, 1 가로, 2 역가로, 3 사선, 4 내려베기, 5 회전, 6 찌르기, 7 검기, 8 방어, 9 연무 |
| `parryable` | 적 공격을 E 로 막을 수 있는지(강인병 내려찍기 false) |
| `knockdown / guard_break / ignores_boss_flinch` | D 다운 / Q 강인병 무너짐 / Q·W·R 보스 무반응 |
| `lock_after_cancel / move_cancel_ms / dodge_cancel_ms` | 신규 스킬의 취소 창과 취소 뒤 남은 행동 제한 |
| `shape_ellipse / ellipse_rx / ellipse_ry` | 바닥 타원 판정(강인병 내려찍기) |
| `guard / counter_attack` | E 방어 창(startup_ms 동안)과 성공 반격 동작 |
| `multi_hits / multi_hit_interval_ms / multi_hit_active_ticks / knockback_last_hit_only` | R 다단히트 |
| `fires_projectile / projectile_*` | W 검기 투사체(속도·사거리·높이·판정·수명·관통 수) |
