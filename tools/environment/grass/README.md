# Grass tile pipeline (HWR-GRASS-001)

Turns the user's Tripo grass block (1,929,690 triangles, 60 MB, Git LFS) into two game tiles of
17,160 triangles with one 2048×1536 atlas each, plus the manifest. Everything is regenerated by

```sh
tools/environment/grass/run.sh
cd game && godot --headless --path . --import
```

| Step | File | Tool | What it does |
| --- | --- | --- | --- |
| 1 | `bake_grass_views.py` | Blender 5.2 LTS (`blender -b`), EEVEE | Orthographic emission-only renders of the source: per Z band top-down colour / world normal (with the source normal map applied) / height, and one front strip (colour+alpha, normal, height) limited to the front 0.07 units. Output `build/*.npy`, `build/bake_meta.json`. |
| 2 | `build_grass_tile.py` | python3 + numpy + Pillow | Height-field turf (128×64 quads), dirt wall welded to the turf edge, four alpha-scissor fin cards; edge bands cross-faded into one mirror-symmetric shared patch; tangent-space normal atlas; GLB writer; `grass_manifest.json` with hashes. |
| 3 | Godot 4.7 import | `--import` | `meshes/generate_lods` builds the LOD chain, textures embedded as Basis Universal (`gltf/embedded_image_handling=2`, same as `wind_spirit`). |

Design notes

- One tile = one village cell (`VillageStage3D.CELL_W × CELL_D` = 2.0 × 0.9). The source is scaled uniformly
  (×2.1978 so the dirt wall spans 2.0) and only a 0.9-deep band is used, so grass is never stretched.
  Variant `a` samples the far band, `b` the near band; 180° rotation is allowed, giving four looks.
- y = 0 is the lowest turf point (the village ground plane). The dirt wall runs down to −0.2 so a tile next
  to a canal (−0.12) never shows a gap. Tips reach ≈ +0.19.
- The bottom face (104k source triangles) and the dirt under the turf are not modelled: invisible.
- UV2.x is the wind bend mask (0 wall/root → 1 tip), UV2.y the part id. `grass_wind.gdshader` reads it.
  COLOR_0 was deliberately not used because glTF viewers multiply it into the base colour.
- Source metallic/roughness map is flat (roughness 0.92 ± 0.04, metallic ≈ 0) so no ORM texture is shipped.
- Decimation candidates (`Collapse` 40k/20k/10k) were rendered for comparison and rejected: UV islands of the
  Tripo atlas collapse into white seams and the turf turns into a lumpy shell (see reports/HWR-GRASS-001.md).
