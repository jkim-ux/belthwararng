## 1. 목표와 시작점
사용자는 M1을 실제로 플레이했고 기본 이동·전투·높이 판정에 만족했다. 평타의 모멘텀을 개선하고 사무라이 소재의 첫 챕터 마을 탈환·관리·동료 합류를 이어서 구현한다.
현재 확인된 M1은 claude/upbeat-mayer-r3t54f의 eaa6309eb79d53cb6434ce73bb00bfa5cb8be1a3, 초안 PR #1이다. main은 확인 시점에 기획 문서가 중심이다. 이 참조는 작업 시작점을 찾기 위한 정보이지 옛 커밋으로 되돌리라는 지시가 아니다.
실제 최신 원격/작업 브랜치/미커밋 변경/완료 보고를 확인한다. 이미 HWR-002를 진행했다면 기존 코드를 보존해 R1 차이만 적용한다. main에서 M1을 새로 작성하지 않는다. 엔진은 기존 버전을 사용하고 개발 중 임의 업그레이드하지 않는다.
main의 최신 TO_CLAUDE.md와 연결 문서를 안전하게 반영한다. 미커밋 변경을 보존하고 충돌은 내용으로 해결한다. 'ours/theirs' 전체 선택, 강제 초기화/강제 푸시로 해결하지 않는다.

## 3. 구현 순서와 완료 기준
각 단계는 자체 실행 가능한 상태로 커밋한다. A~D는 한 작업으로 순서대로 수행하며 단계마다 새 승인을 기다리지 않는다.

### A — 전투를 먼저 비교할 수 있게
1. 현재 화면의 화랑/신라 표시를 사무라이 배경으로 전환. A/S는 돌진베기/올려베기, 나머지 표시명은 기획 표에 맞춤. 내부 ID/경로/작업 이력은 호환 유지.
2. 전투 상세 문서의 전진/감속 피격/몸·검 시각 동작 구현.
3. 수련장 기존/새 프로필 비교. 기존 조작 타이밍 유지, 변경 파라미터는 리소스화.
4. 실제 이동 합, 경계/취소/히트스톱, 왼쪽·오른쪽 3연타 연결과 M1 회귀 검증.
완료: 새 모멘텀으로 평타를 확인할 수 있고, 판정과 입력 연결이 계속 작동한다.

### B — 첫 마을 한 바퀴
1. 시작 화면·지도·관리 화면과 영구 CampaignState 마련.
2. 농촌 거점의 전투·웨이브·승패 연결. 수련장 Dummy/리셋 기능과 분리.
3. 최초100/반복20, 정비40, 훈련장60→공격력+5%, 전경 상태 변화.
4. 저장 후보 상태 처리, 재실행 복원, 보상/구매 중복·실패 검증.
완료: 새 게임→농촌 승리→정비→훈련장→저장→재실행이 이어지고 효과가 정확히 한 번 적용된다.

### C — 첫 챕터 완주
1. 창고 마을과 초소, 정의 데이터로 관리도/선행 조건 연결.
2. 창고 보급창60→최대체력+10, 초소 대장2패턴, 근접 동시 공격 제한.
3. 초소 승리→챕터1 클리어/궁수 해금/합류 화면을 한 결과로 연결.
4. 5챕터 지도, 잠긴 동료4명 데이터. 미구현 챕터는 조건을 만족해도 들어가지 못함.
완료: 반복 사냥 없이 관리와 선택 시설 구매를 하며 초소까지 승리할 수 있다. 군사 초소에 불필요한 마을 구매 화면이 없다.

### D — 동료를 실제로 써보기
1. 궁수 선택/동행 해제, 실제 따라가기·깊이 맞추기·사격·피격·이탈 구현.
2. 팀/참여자/적 대상 선택/투사체/승리의 연결. 주인공만을 고정 참조하는 기존 경로를 확인.
3. 동료 해금 직후 기존 거점 재도전 안내, 선택 상태 저장.
4. 동료 마지막 처치·주인공 사망·아군 오인 피해·투사체 종료·상태 복원 검증.
완료: 궁수와 농촌을 재도전해 함께 싸우며, 이탈/승패/보상이 실제로 처리된다.

## 5. 검증과 최종 보고
