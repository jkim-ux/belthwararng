## 목표

임시 도형으로 표현한 화랑이 평평한 전투 공간에서 이동, 점프, 회피, 평타 3연격, 비연참과 승월참을 사용할 수 있게 한다. 허수아비와 단순 근접 적을 넣어 손맛을 확인한다. 한 번의 실행으로 이동부터 타격과 피격까지 검증할 수 있는 프로젝트를 제출한다.

## 시작 전 확인

프로젝트의 기존 지침과 파일, 설치된 Godot 버전을 확인한다. 기존 프로젝트가 있으면 이어서 사용한다. 새 프로젝트는 Godot 4 계열의 설치된 안정 버전과 GDScript를 기본안으로 하며 정확한 엔진 버전을 실행 안내에 기록한다. 엔진을 실행할 수 없다면 그 제약을 먼저 밝히고 코드 작성과 실제 실행 확인을 구분한다.

[전체 기획](../docs/GAME_DESIGN.md)의 전투 규칙과 M0·M1 범위를 기준으로 삼는다. 아래 내용과 기획이 충돌하면 사용자의 최신 지시를 확인하고 충돌을 보고한다.

## 구현 내용

1. 실행 가능한 전투 장면 1개와 범위가 보이는 바닥 및 벽을 만든다.
2. 방향키로 지상 x·y 이동을 구현한다. 대각선 입력을 정규화한 뒤 축별 속도를 적용한다.
3. 점프 높이 z를 별도로 관리한다. 그림자와 그리기 순서는 바닥 위치를 따른다.
4. X 평타 3연격, C 점프와 공중 평타 1회, Space 회피를 구현한다.
5. A 비연참과 S 승월참을 구현한다. 8개 스킬을 확장할 데이터 구조를 마련한다.
6. 허수아비와 접근·예고·공격·회복을 수행하는 근접 적을 만든다.
7. 허수아비 및 적을 다시 생성하는 개발용 동작을 넣는다.
8. 체력, 사용 가능한 스킬, 재사용 시간을 표시한다. 미구현 스킬을 사용 가능한 것처럼 표시하지 않는다.
9. 개발용 모드에서 바닥 위치, 높이, 공격·피격 범위, 현재 행동을 확인할 수 있게 한다.

## 초기 전투 수치

| 항목 | 초기값 |
| --- | --- |
| 기준 화면 | 1280 × 720 |
| 고정 시뮬레이션 | 매초 60회 |
| 이동 속도 | 좌우 300 px/s, 깊이 200 px/s |
| 가속 및 감속 | 약 50 ms 및 40 ms |
| 입력 보관 | 최근 유효 행동 1개, 120 ms |
| 타격 정지 | 일반 35 ms, 강공격 60 ms |
| 회피 | 이동 180 ms, 시작부터 무적 100 ms, 재사용 0.9초 |
| 평타 연결 구간 | 현재 평타의 마지막 100 ms |
| 비연참 | 재사용 4초, 피해 120%, 무적 없음 |
| 승월참 | 재사용 6초, 피해 150%, 일반 적을 짧게 띄움 |

값은 에디터에서 수정 가능해야 한다. 고정 틱에 맞춰 실제 적용 시간이 달라지면 적용값을 기록한다. 초기값 변경이 필요한 경우 이유와 변경값을 보고한다.

## 반드시 지킬 판정과 행동 규칙

바닥의 깊이와 높이가 맞아야 공격이 적중한다. 한 타의 공격 인스턴스와 대상 조합에는 피해가 한 번만 적용된다. 타격 정지 중에도 입력을 수집하고, 여러 적을 맞혔다고 정지 시간을 합산하지 않는다.

평타와 스킬의 준비·타격·회복 구간을 구분한다. 지정 연결 구간에서만 다음 평타나 스킬로 연결한다. 만료된 입력과 사망 전 입력은 나중에 실행되지 않아야 한다. 공격 중 좌우 방향은 고정한다. 띄워진 일반 적에게 재차 띄우기가 적용되지 않아야 한다.

## 이번 범위 밖

나머지 스킬 6개, 보스, 마을 관리, 장비, 추가 마을, 멀티플레이, 최종 아트는 후속 작업이다. 첫 전투 실험의 실행과 검증을 우선한다.

## 완료 기준

- 프로젝트를 열고 전투 장면을 실행하는 방법이 문서에 있다.
- 이동, 점프, 회피, 평타 3연격, 비연참, 승월참을 확인할 수 있다.
- 다른 깊이의 적에게 근접 공격이 빗나가며, 높이별 판정도 규칙과 일치한다.
- 한 번의 공격에 같은 대상이 중복 피해를 받지 않는다.
- 입력을 조금 일찍 눌렀을 때 지정한 연결 구간에서 이어진다.
- 한참 전에 누른 입력이 뒤늦게 발동하지 않는다.
- 1분 이상 반복 조작하며 공격·피격·회피를 확인할 수 있다.
- 검증에 사용한 환경과 실제 확인 결과를 기록했다.
