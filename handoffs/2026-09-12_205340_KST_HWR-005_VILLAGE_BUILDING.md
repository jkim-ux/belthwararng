## 작업 기준
사용자가 원하는 것은 실제 지면에 건물을 배치하고 마을이 변하는 경험이다. 첫 검수는 캐릭터 이동→개간→농장/우물/수로 배치→공사→주민 배정→작물 성장→수확까지 직접 조작으로 수행한다.
마지막 확인 코드는 claude/upbeat-mayer-r3t54f의 bf014527d4a6a01dddfc6dbc54fc9fc86b594a88, PR #1의 HWR-003 구현이다. 최신 브랜치·미커밋 변경·reports를 먼저 확인하고 더 최신인 HWR-004 작업이 있으면 보존한다. 해당 커밋으로 되돌리거나 main에 game/가 없다고 재작성하지 않는다.
HWR-004 R1은 별도로 보완한 전투 지시다. 이번 마을 작업은 기존 HWR-003의 캠페인·저장 위에서 시작할 수 있으며 미완료 전투 스킬 전체를 마을 지시에 묶어 재구현할 필요는 없다. 진행 중인 작업을 버리지 않고 충돌 없는 부분을 이어 간다.

## 구현 순서
1. Village 장면·플레이어·카메라·32×24 격자·건설 미리보기·회전·점유/통로 검증.
2. 기존 CampaignState에 자원과 마을 인스턴스 상태를 추가하고 schema1→2 이전·원자 저장. 개간/공사/이동/취소 연결.
3. 농장·우물·수로·작은 보 구현. 연결망의 공급 용량·끊김·농사3단계·수확1회 처리.
4. 주민3명 초기화·일손 배정·이동/도착/작업, 벌목소·채석장·식사·주택 귀환.
5. 농촌·창고의 개별 템플릿, 물리적 경로 복구·훈련장·보급창·기존 다음 거점 조건 연결.
6. 실제 첫 수확 플레이, 경제 장부, 저장 이전/실패·기존 캠페인 회귀 보고.

기존 입력을 전투와 분리한다. E/B/R·마우스 조작이 전투 스킬을 시전하거나 UI 아래 칸을 함께 설치하지 않게 한다.
주민 길 찾기·건설·관개는 실제 상태다. 수치가 먼저 오르고 주민은 장식으로 걷기만 하는 구현은 완료가 아니다.
재료 차감·배치와 생산 보상은 동일한 후보 상태로 한 번 처리한다. 작업별 고유 ID를 사용하고 정의 Resource를 실행 중 수정하지 않는다.

## 반드시 지킬 경제·진행
- 첫 농촌 초기화 목재60/석재40/식량20은1회, 기존 군자금/시설/동료는 보존.
- 첫 농촌 승리100으로 경로 복구40+훈련장60, 재료는 기본 물자로 농장/우물/수로8칸까지 가능.
- 군자금/재료 부족·식량0에서 개간/농사로 복구 가능. 식량이 출정 요금이나 주민 사망 조건이 되지 않음.
- 경로 복구 완공→관리도60, 특수 시설 완공→기존+5%/+10 한 번. 기존 구매는 무료 완공 건물로 이전.
- 마을당 초기3명·주택 최대2채·채당2명 귀환. 한 주민 한 작업, 재로드/이동으로 재귀환 없음.
- 경제 시간은 현재 마을에서만 진행. 전투/지도/다른 마을/일시정지/오프라인 생산은 이번에 없음.
- 강가 보와 수로는 직접 배치 가능한 기반 시설. 물 효과는 연결망·공급량으로 판정하며 실제 유체 계산은 필요 없음.

## 검증·완료
VILLAGE_BUILDING의 인수 표를 모두 확인하고 미수행은 이유를 적는다. 실패 입력의 자원 불변, 관개 끊김/복구, 농장 주기 중 주민 변경, 동일 틱 수확+이동/철거, 저장 재시도 중 보상 복제 여부를 검수한다.
기존 schema1의 미진행/농촌만 해방/시설 구매/아야 해금 상태를 별도 테스트 저장으로 이전한다. 플레이어의 실제 저장을 테스트용으로 덮지 않는다.
정비/시설의 버튼 즉시 구매를 기대한 기존 시험은 새 공사 완료 규칙으로 갱신하고, 변경하지 않은 전투·방·상자·보스·동료·영구 보상 검증은 유지한다.
reports/HWR-005.md와 재현 입력/스크린샷 또는 짧은 영상, 실행 방법을 남긴다. 단계별 커밋·허용 브랜치 푸시·필요한 초안 PR 갱신까지 하되 main 자동 병합은 하지 않는다.
