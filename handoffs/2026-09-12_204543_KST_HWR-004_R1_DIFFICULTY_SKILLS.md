## R1에서 보완한 사항
기존 HWR-004를 새로 시작하는 작업이 아니다. 이미 작업 중이면 아래 차이를 적용한다. [최초 지시](2026-09-12_202434_KST_HWR-004_DIFFICULTY_SKILLS.md)는 이력이며 세부 충돌은 R1이 우선이다.
- 불은 E를 막거나 소모하지 않으며 HP만 감소한다. 실제 경직/사망만 반격 예약을 취소한다.
- E의 정면/반격 가능 공격 목록/12틱 창/성공·실패 후 취소 시점을 확정했다.
- 이동 취소로 다른 스킬의 후딜 제한을 우회하는 현재 Player 경로를 막는다.
- D의 공중 적 예외 처리 순서, W의 별도 투사체·관통 순서·수명, R의5개 판정과 시전별 중복 방지를 명시했다.
- 강인병과 보스의 면역/공격 허가/거리 선택/예고 모양과 판정, Q 이후 복귀를 명확히 했다.
- 동일 틱의 방어·피해·취소·사망 순서와 취소된 HitBox 복사본을 검수한다.
- 상세 문서8절 구현 계약과9절 추가 인수 기준까지 적용한다. 기존9개 기준도 유지한다.

## 시작과 범위
사용자는 최신 전투 느낌에 만족했고 난도는 여전히 낮다고 했다. 적 피해2배는 전 적 피해에 적용하고 첫 농촌 battle_1은 경직 반응 튜토리얼로 유지한다. 강인병의 첫 등장은 농촌 battle_2다.
확인한 HWR-003 코드는 claude/upbeat-mayer-r3t54f의 bf014527d4a6a01dddfc6dbc54fc9fc86b594a88, PR #1이다. 실제 최신 코드/미커밋 변경/완료 보고를 확인해 이어서 작업하고 옛 커밋으로 되돌리지 않는다.
main의 최신 문서를 기존 구현에 안전하게 반영한다. 엔진 버전·config/name·저장 위치·거점/스킬 내부ID는 유지한다. 스토리 집필과 새 챕터는 별도다.

## 구현 순서
1. 현재 enemy/archer/captain/fire 피해값10/8/12/3을20/16/24/6으로 바꾸고 각 실제 경로를 검증한다. 아야7과 플레이어 피해에는 적용하지 않는다.
2. BruteEnemy와 강인 반응/두 패턴/Q 전용 파훼 연결점을 구현한다. 일반 적과 보스에 맞는 피격 hitstop 정책을 분리한다. 보스의 거리 기반 패턴 선택/회복 재배치를 보완한다.
3. D내려베기/F회전베기/Q방어깨기/W검기를 구현한다. Q는 강인병1초 제어, W는 실제 관통 투사체다.
4. E흘려받기/R일섬연무를 구현한다. 반격 소비와 실제 피해를 구분하고 다단히트의 타격별 중복 방지를 구현한다.
5. 교체 배치/튜토리얼 안내/수련장/HUD8칸을 연결하고 같은 조건의 난도 비교와 던전·캠페인 회귀를 수행한다.

단계별 실행 가능한 커밋을 남기고 전체 작업을 계속 진행한다. Q/R이 아직 없다고 강인병 구현을 완료 상태로 방치하지 않는다. 실제 완료 때 모든8개 스킬을 쓸 수 있어야 한다.

기존 ID: D=nakhwagyeok, F=hoepungcham, Q=pajingyeok, W=banwolgeomgi, E=yusubangyeok, R=hwarangnanmu. 사용자 표시명과 내부ID를 혼동해 파일을 불필요하게 바꾸지 않는다.
HitInfo 결과는 실제 피해/방어 성공/무효를 구분할 수 있게 한다. E로 막은 타격을 applied_targets에 기록하지 않아 다음 틱 다시 맞거나, 무피해 방어를 실제 피해로 집계하지 않게 한다.
강인병은 경직뿐 아니라 피격 타격 정지·밀림·띄우기·다운 면역이다. HP와 명중 표시는 정상 적용하며 Q만 전용1초 제어를 한다. 면역을 alive=false/invuln으로 흉내내지 않는다.
R은5개 hit_index, W는 투사체당 대상1회. 이 기준으로 기존 actor/hitbox 배열 순회와 방 전이 정리를 확인한다.

## 검증과 보고
DIFFICULTY_AND_SKILLS의9개 인수 항목을 실제로 검증한다. 적 피해10 등을 기대한 기존 검증은 새 요구20에 맞춰 바꾸고 변경 이유를 적는다. 전투 모멘텀/입력/방 이동/상자/마을/동료/저장 검증을 무의미하게 제거하지 않는다.
강인병이 반복 공격을 받는 동안 실제 준비·공격 틱이 진행하는지 확인한다. 'hitstun 상태에 안 들어갔다'만 검사하면 충분하지 않다.
E/R/불/반격 불가·동시 공격 경계, Q무너짐 비연장, 기존저장→8스킬 사용, 방 이동 뒤 잔여 판정을 확인한다. 테스트 저장은 별도 경로다.
